# 혜림님께: 화면 수정 내용과 서버 부탁

## 1. 화면에서 바뀐 것

- 전체 리디자인을 적용했어요. 파랑+크림, 나눔고딕, 모바일 390px, 하단 탭 5개(내 기록·챌린지·홈·커뮤니티·더보기)입니다.
- 서버에 있는 새 API를 화면에 연결했어요.
  - 닉네임
  - 커뮤니티 글·댓글·좋아요·신고
  - 파이
  - 공통 챌린지(목록·참여·인증·순위)
  - 글에 챌린지 붙이기
  - 관리자 신고 처리, 공통 챌린지 관리
- 화면 PR은 서버 PR(`yiseul_2`)이 머지·배포된 뒤에 올려요. 약관 동의 문구를 서버와 맞춰야 해서 순서가 중요해요.
- 서버에 아직 없는 기능은 화면에 "준비 중"으로 표시했어요.
  - 배지
  - 캐릭터·상점
  - 파티
  - 사진 인증
  - 파이 적립(미션 완료·5일 연속·4주 완주)

## 2. 시안에서 정리한 것 (파티)

- "개시자"를 "파티장"으로 바꿨어요.
- 파티 현황은 파티원 모두가 같은 챌린지 1개를 인증하는 구조로 그렸어요.
- 파티 현황 화면에 필요한 값은 아래와 같아요.

| 값 | 설명 |
|---|---|
| 파티 챌린지 이름 | 파티원 모두 같은 챌린지 |
| 파티원별 오늘 완료/미완료 | 오늘 인증했는지 |
| 파티원별 "N일 중 M일" | 시작 후 경과 일수 중 인증한 일수. 파티장도 동일 |

## 3. 서버에 부탁드릴 것

1. **12주 번호**: "지난 12주 기록"에서 몇 번째 12주인지 구분이 필요해요. 지금은 화면에서 `cycle_number`를 3개씩 묶어 임시로 만들었어요. 번호와 연·월·limit·offset 조회가 생기면 바꿔요.
2. **챌린지 참여 인원**: 챌린지 선택 화면과 파티 화면에 보여줘요.
3. **미션 구분 필드**: 응답에 `mission_role`(고정/선택)이 없어서, 화면에서 코드 앞자리(`SMK`, `ALC`)로 고정 챌린지를 판단하고 있어요. 필드로 내려주면 바꿔요.
4. **캐릭터·상점·파티·배지 API**: 나오는 대로 화면을 채워요.
5. **파이 적립 연결**
   - 오늘 미션 모두 완료: +5
   - 5일마다 연속 달성: +10
   - 4주 챌린지 완주: +50
