# 파이온 개인정보 처리방침 (v4 최종안)

> 작성 기준: 필라이즈(2024-08-01), 파스타, 셀비 체크업(2024-03-14) 처리방침의 공통 구조를 따르고, 파이온의 현재 동작을 사실대로 적었습니다. 법률 검토를 거친 문서가 아닙니다.
> `[확정 필요]`와 `[게시 전 확인]`은 결정이나 작업이 끝나야 채우거나 지울 수 있는 곳입니다. 시행일(2026-10-22)과 체험 기간(2026-10-22 ~ 2026-10-25 23시 59분)은 확정해서 채웠습니다.

## 제1조 (개인정보의 처리 목적)

파이온 팀(이하 "운영팀")은 다음 목적을 위해 개인정보를 처리합니다. 목적이 바뀌면 필요한 동의를 다시 받습니다.

1. 회원 가입과 관리: 가입 의사 확인, 본인 계정 식별, 로그인 유지, 부정 이용 방지
2. 서비스 제공: 건강정보와 생활습관 설문을 바탕으로 한 10년 내 심장 혈관 건강 신호 분석, 혈압 상태 안내, 나와 비슷한 사람과의 비교, 12주 생활습관 챌린지 기록과 4주 전·후 비교, 캘린더 기록
3. 서비스 운영 점검: 챌린지 참여 현황 등 통계 확인(개인을 알아볼 수 없는 집계), 관리자 행위 기록 점검
4. 커뮤니티 운영: 닉네임·게시글·댓글 표시, 신고 처리, 캐릭터·파이·배지 제공, 공통 챌린지 순위 계산과 보상 지급, 파티 운영
5. 문의와 불만 처리

이 서비스는 의료 행위가 아니며, 분석 결과는 참고용입니다.

## 제2조 (처리하는 개인정보 항목)

| 구분 | 항목 | 수집 방법 |
|---|---|---|
| 가입·로그인 (필수) | 이메일, 비밀번호(해시로 저장, 원문은 저장하지 않음), 생년월일 | 가입 화면 |
| 건강정보 (필수, 별도 동의) | 성별, 대상 확인 답(나이대, 심장 혈관 질환 진단 여부, 응급 증상 여부), 키, 몸무게, 허리둘레, 혈압, 흡연·음주 등 생활습관, 당뇨·고혈압 진단 및 치료 여부, 부모의 고혈압 여부, 총콜레스테롤(선택) 등 건강기록 | 건강정보 입력 화면 |
| 설문·챌린지 | 생활습관 설문 답변, 챌린지 선택과 수행 기록, 4주 재입력 값 | 설문·챌린지 화면 |
| 캘린더 | 일기, 사진, 건강 할 일 | 캘린더 화면 |
| 커뮤니티 | 닉네임, 게시글, 댓글, 좋아요, 신고 내용(신고한 계정 포함), 캐릭터 설정 (건강정보와 개인정보는 쓰지 않도록 안내) | 커뮤니티·캐릭터 화면 |
| 파이·배지·공통 챌린지·파티 | 파이 적립·사용 내역, 배지, 공통 챌린지 참여와 인증 기록(인증한 날짜, 걸음 수로 인증하는 챌린지는 그날의 걸음 수), 파티 이름과 파티원 | 챌린지·커뮤니티 화면 |
| 자동 생성 | 동의 기록(정책 ID·버전·동의 시각), 로그인 세션 기록, 탈퇴·동의 철회 처리 기록, 관리자 행위 기록(관리자 이메일, 시각, 동작·대상) | 서비스 이용 과정 |
| 문의 | 1:1 문의의 제목·내용·답변(건강정보가 포함될 수 있음) | 마이페이지 1:1 문의 |
| 비회원 문의 | 로그인·가입이 안 될 때 로그인 없이 남기는 문의의 제목·내용·답변, 조회 번호와 접속 IP(원문이 아닌 해시 값으로만 저장, IP는 횟수 제한에만 사용) | 로그인 화면의 비회원 문의 |
| 서비스 접속 기록 | 로그인한 계정 번호, 로그인 시각, 접속 IP | 로그인할 때 자동 |

- 이름과 전화번호는 수집하지 않습니다.
- 만 19세 미만은 가입할 수 없으며, 만 19세 미만의 개인정보는 수집하지 않습니다.

## 제3조 (개인정보의 보유와 이용 기간)

| 정보 | 보유 기간 |
|---|---|
| 가입·로그인, 건강정보, 설문, 챌린지, 캘린더 | 회원 탈퇴 시까지. 탈퇴하면 즉시 삭제합니다. |
| 건강정보 | 동의를 철회하면 건강기록·설문·분석·챌린지·캘린더·대상 확인·성별과 파이·배지·파티·공통 챌린지 기록을 즉시 삭제합니다(계정, 닉네임, 게시글, 댓글, 캐릭터는 유지). |
| 동의 기록 | 탈퇴할 때 삭제합니다. |
| 로그인 세션 기록 | 로그아웃하면 기록을 지우지 않고 폐기했다는 표시를 남깁니다. 탈퇴할 때 삭제합니다. |
| 관리자 권한 부여·변경·말소 이력 | 3년 보관합니다. 개인정보의 안전성 확보조치 기준(접근권한 부여·변경·말소 내역은 3년 이상)에 따르며, 일반 관리자 행위 기록(2년)과 따로 보관합니다. |
| 관리자 행위 기록(접속기록) | 2년 보관합니다. 개인정보의 안전성 확보조치 기준(민감정보를 처리하는 시스템은 2년 이상)에 따릅니다. 사용자의 개인정보는 담지 않습니다. |
| 서비스 접속(로그인) 기록 | 3개월 보관하고, 3개월이 지난 기록은 자동으로 삭제합니다. 탈퇴한 뒤에도 보관 기간 동안은 남습니다. 보안 점검과 부정 이용 방지를 위한 것이며, 통신비밀보호법의 로그기록자료·접속지 추적자료 보관 기준(3개월)을 참고했습니다. |
| 1:1 문의(제목·내용·답변) | 회원 탈퇴 시 삭제합니다. 건강정보 동의를 철회해도 문의는 삭제되지 않습니다. 체험이 끝나면 탈퇴하지 않은 이용자의 문의도 일주일 안에 삭제합니다. |
| 비회원 문의 | 접수한 날부터 30일이 지나면 삭제합니다. |
| 닉네임·게시글·댓글·좋아요·캐릭터 | 탈퇴하면 삭제합니다. 이용자가 직접 삭제한 글·댓글은 즉시 삭제합니다. 건강정보 동의를 철회해도 삭제되지 않습니다. |
| 파이·배지·파티·공통 챌린지 기록 | 탈퇴하면 삭제합니다. 건강정보 동의를 철회하면 함께 삭제합니다. |

- **체험 버전**: 체험이 끝나는 날부터 일주일 안에 탈퇴하지 않은 이용자의 정보도 삭제합니다. 체험 기간은 2026-10-22부터 2026-10-25 23시 59분까지이며, 2026-11-01까지 삭제합니다.
- **서버 백업 사본**: 삭제한 건강정보는 백업 사본에 최대 일주일 더 남아 있다가 지워집니다. 다만 아래 기록은 삭제한 건강정보와 따로 보관하며, 관리자 행위 기록은 2년, 관리자 권한 부여·변경·말소 이력은 3년, 이용자 접속(로그인) 기록은 3개월 동안 남습니다.
- **법령에 따라 보관해야 하는 정보**: 파이온은 결제, 상품 배송 등 법령상 별도 보관 대상이 되는 정보를 처리하지 않습니다. 다만 관리자 접속 기록(2년)과 관리자 권한 부여·변경·말소 이력(3년)은 개인정보의 안전성 확보조치 기준에 따라 보관하고, 이용자 접속(로그인) 기록(3개월)은 보안 점검을 위해 보관합니다(위 표 참고).

## 제4조 (개인정보의 제3자 제공)

파이온은 이용자의 개인정보를 제3자에게 제공하지 않습니다. 법령에 근거가 있는 경우에만 예외로 합니다.

## 제5조 (개인정보 처리의 위탁)

| 수탁자 | 위탁 업무 | 위탁 기간 |
|---|---|---|
| Amazon Web Services(서울 리전) | 서버 운영, 데이터베이스 저장 | 서비스 종료 또는 계정 삭제 시까지 |

- 이 밖에 개인정보 처리를 맡기는 곳은 없습니다.
- 이용자 설문은 서비스와 별개로 구글 폼으로 받으며, 설문 안에서 따로 안내하고 동의를 받습니다. 1:1 문의와 비회원 문의는 서비스 안에서만 처리하며 외부 서비스로 보내지 않습니다.

## 제6조 (개인정보의 국외 이전)

서비스 서버와 이용자의 정보(건강정보, 가입 정보, 문의 내용, 커뮤니티 기록 포함)는 대한민국(AWS 서울 리전)에 저장되며 국외로 이전하지 않습니다. 문의도 서비스 안에서만 처리합니다.

## 제7조 (개인정보의 파기)

1. 회원 탈퇴를 요청하면 비밀번호로 다시 확인한 뒤, 이용자 번호가 연결된 건강정보, 설문, 분석, 챌린지, 캘린더 기록, 닉네임, 게시글, 댓글, 좋아요, 신고, 캐릭터, 파이, 배지, 파티와 공통 챌린지 기록, 동의 기록, 로그인 세션을 데이터베이스에서 삭제합니다.
2. 계정 기록은 지우지 않고 이메일을 알아볼 수 없는 값으로 바꾸고 비밀번호를 사용할 수 없게 교체해 로그인할 수 없게 합니다. 탈퇴 요청·처리 시각과 삭제 건수 요약은 기록으로 남습니다. 탈퇴한 뒤에도 같은 이메일로 다시 가입할 수 있습니다.
3. 삭제한 정보가 서버 백업 사본에는 최대 일주일 더 남아 있다가 지워집니다.
4. 체험이 끝나면 제3조에 따라 탈퇴하지 않은 이용자의 정보도 삭제합니다.

## 제8조 (정보주체의 권리와 행사 방법)

| 권리 | 행사 방법 |
|---|---|
| 열람 | 마이페이지의 "내 데이터 내려받기"(JSON)와 "내 데이터 PDF로 받기" |
| 정정 | 건강정보는 "건강정보 수정하기", 생년월일·성별은 마이페이지의 "내 정보"에서 직접 수정. 이메일 주소를 바꾸려면 1:1 문의로 요청(로그인이 안 되면 비회원 문의) |
| 삭제 | 마이페이지의 "회원 탈퇴" |
| 처리정지·동의 철회 | 마이페이지의 "건강정보 처리 동의 철회". 철회하면 건강정보와 파이·배지·파티·공통 챌린지 기록이 삭제되고, 계정과 닉네임·게시글·댓글·캐릭터는 유지됩니다. 철회하면 서비스를 이용할 수 없습니다. 이 경우 로그인, 다시 동의, 1:1 문의, 회원 탈퇴만 할 수 있습니다. 다시 동의하면 다시 이용할 수 있습니다. |

화면에서 할 수 없는 요구는 마이페이지의 1:1 문의로 보내 주세요. 로그인이 안 될 때는 로그인 화면의 비회원 문의로 보내 주세요(건강정보는 적지 마세요). 대리인이 요청할 때는 본인과 대리인을 확인할 수 있는 자료를 요청할 수 있습니다.

## 제9조 (안전성 확보 조치)

- **비밀번호**: bcrypt로 해시해 저장하며 원문은 저장하지 않습니다.
- **통신 구간**: 서비스 접속 구간은 HTTPS로 암호화됩니다.
- **저장**: 서버 저장소(디스크)는 2026-10-17부터 암호화되어 있습니다. 이메일은 데이터베이스에서 항목별로 따로 암호화해 저장하며, 로그인 확인용으로는 이메일에서 만든 해시 값을 따로 저장합니다. 생년월일·성별, 건강정보 등은 항목별로 따로 암호화하지는 않습니다.
- **접근 권한 관리**: 서버에 직접 접속할 수 있는 개발팀원은 1명이고, 배포를 통해 서비스를 올릴 수 있는 개발팀원은 4명입니다. 이들은 서비스 점검을 위해 저장된 값을 볼 수 있으며, 테스트 목적 외에는 사용하지 않습니다. 관리자 화면은 관리자로 등록된 계정만 쓸 수 있고, 이메일은 가려서 보여 주며 전체는 필요할 때만 열람합니다(열람할 때마다 관리자 행위 기록에 남깁니다).
- **접근 통제**: 데이터베이스는 서버 밖에서 직접 접속할 수 없도록 막았고, 접속 정보와 비밀값은 저장소에 올리지 않고 서버 설정 파일에만 둡니다.
- **접속 기록**: 관리자의 열람·변경 기록(관리자 이메일, 시각, 동작·대상)을 남기고 점검합니다. 관리자 권한 부여·회수 이력도 서버가 켜질 때 기록합니다.
- **인증**: 접근 토큰은 짧은 유효기간(현재 30분)을 두고, 재발급용 토큰은 해시 값만 저장합니다. 탈퇴하면 계정이 삭제되고, 동의를 철회하면 로그인·동의·문의·탈퇴를 뺀 서비스 요청이 막힙니다.
- **점검**: 서버 상태와 백업은 자동으로 점검하고 이상이 있으면 알림을 받습니다.

인터넷은 완전히 안전한 환경이 아니므로, 운영팀이 보안 조치를 하더라도 정보가 노출되거나 변경될 가능성이 없다고 보장하지는 않습니다.

## 제10조 (로그인 정보 저장과 쿠키)

로그인을 유지하기 위해 이 브라우저의 저장소(localStorage)에 로그인 토큰을 저장합니다. 로그아웃하거나 탈퇴하면 지워집니다. 서비스는 광고나 방문 분석을 위한 쿠키를 쓰지 않습니다.
글꼴도 우리 서버에서 직접 제공해서 외부 글꼴 서버를 부르지 않습니다.

## 제11조 (개인정보 보호책임자)

- 담당: 파이온 팀
- 문의: 서비스 안 1:1 문의(마이페이지). 로그인·가입이 안 될 때는 로그인 화면의 비회원 문의
- 열람·정정·삭제·처리정지 요청과 개인정보 관련 불만은 위 문의로 접수하며, 접수한 사항은 지체 없이 처리하고 늦어지면 사유와 일정을 알려 드립니다. 문의에는 건강정보와 불필요한 개인정보를 적지 마세요.

## 제12조 (권익침해 구제 방법)

- 개인정보 분쟁조정위원회: www.kopico.go.kr
- 경찰청 사이버범죄 신고시스템: ecrm.police.go.kr (민원상담 182)

## 제13조 (처리방침의 변경)

1. 처리방침을 바꿀 때는 적용일, 변경 내용과 이유를 서비스 안에서 적용일 7일 전부터 알립니다. 이용자에게 불리한 변경은 30일 전부터 알립니다.
2. 이전 방침과 변경 내용은 이 화면의 "변경 이력"에서 확인할 수 있습니다. 변경 이력에는 바뀐 날짜, 대상, 바뀐 내용, 바뀐 이유를 적습니다.
3. 새로 동의가 필요한 변경은 이용자가 다시 동의해야 적용됩니다.
