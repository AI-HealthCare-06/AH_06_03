ALCOHOL_FREQ(BD1_11): never_lifetime / none_past_year / lt_monthly / monthly / 2_4_per_month / 2_3_per_week / 4plus_per_week

BP_STAGE(계산, 명세 §6 HE_HP 기준): normal / elevated / prehypertension / hypertension — 모델이 아닌 규칙 판정
