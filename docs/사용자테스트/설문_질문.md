# 사용자 테스트 설문 — 체험 후 설문 (13문항, 약 3분)

지인 체험 후 구글 폼으로 받는 설문이다. 이름·이메일은 받지 않는다. 폼은 `구글폼_생성.gs`(Google Apps Script)로 만든다.

- 폼 제목: PAEON 체험 후 설문 (약 3분)
- 폼 설명: 체험해 주셔서 감사합니다. 정답은 없어요, 솔직한 느낌을 알려주세요!
- 확인 메시지: 응답이 기록됐어요!

## 구성과 분기

| 섹션 | 문항 | 내용 |
|---|---|---|
| 1. 시작 | 1 | 연령대 |
| 2. 사용 경험 | 2~5 | 어디까지 해봤는지, 서비스 이해, 막힌 곳, 속도 |
| 3. 계속 사용 의향 | 6 | 계속 쓰고 싶은지 (분기) |
| 4. 이유 | 7~8 | **6번에서 "그렇지 않다·전혀 그렇지 않다"를 고른 사람만** |
| 5. 개선과 가격 | 9~13 | 계속 쓴다면 이유, 필요한 것, 구독료 구간, 광고, 자유 의견 |

6번에서 "매우 그렇다·그렇다·보통이다"를 고르면 섹션 4를 건너뛰고 섹션 5로 간다. 낮게 답한 사람도 섹션 5(가격·광고·자유 의견)를 거친다. 가격 구간에 "무료일 때만"이 있고, 낮은 의향 응답자의 개선 의견과 자유 의견이 가장 값지기 때문이다.

## 문항

1. 연령대를 알려주세요. (필수) 10대 / 20대 / 30대 / 40대 / 50대 / 60대 이상
2. 어디까지 해보셨나요? (필수, 복수 선택) 가입 / 건강정보 입력 / 결과 확인 / 챌린지 시작 (미션 고르기) / 오늘 미션 기록하기
3. 이 서비스가 어떤 도움을 준다고 설명하시겠어요? (필수, 단답)
4. 사용 중 막히거나 헷갈린다고 느낀 적이 있었나요? (해당하는 항목을 모두 골라주세요) 가입·로그인 / 대상 확인 (나이·병력 질문) / 건강정보 입력 / 생활습관 설문 / 결과 화면 / 챌린지 미션 고르기 / 미션 기록 / 4주 재입력 / 없었어요 / 기타(직접 입력)
5. 서비스를 쓰면서 화면이 늦게 뜨거나 버벅인다고 느낀 적이 있나요? (필수) 전혀 없었어요 / 한두 번 있었지만 불편하지 않았어요 / 여러 번 있어서 불편했어요 / 너무 느려서 쓰기 어려웠어요
6. 이 서비스를 앞으로도 계속 쓰고 싶으신가요? 솔직하게 말씀해주시면 큰 도움이 돼요! (필수) 매우 그렇다 / 그렇다 / 보통이다 / 그렇지 않다 / 전혀 그렇지 않다
7. 계속 쓰기 어려운 가장 큰 이유는 무엇인가요? (필수, 6번이 낮은 경우) 건강 관리에 관심이 없어요 / 웹 서비스 사용이 불편해요 / 분석 결과를 신뢰하기 어려워요 / 챌린지로 생활습관이 개선될지 모르겠어요 / 기타(직접 입력)
8. 좀 더 자세히 알려주실 수 있나요? (선택, 서술)
9. 만약 계속 사용한다면 가장 큰 이유는? (복수 선택, 최대 2개) 현재 건강 정보 확인 (고혈압 위험 정도·혈관 나이 추정) / 챌린지 미션 달성과 보상 획득 / 챌린지 전/후 건강 상태 변화 확인 / 장기적인 생활습관 기록 및 보관 / 해당 없음 / 기타(직접 입력)
10. 더 좋은 서비스를 위해 가장 필요한 것은? (필수, 2개 선택) 더 다양한 챌린지 / 보상 (포인트, 쿠폰 등) / 나의 건강 상태와 위험도에 대한 더 자세한 설명 / 나에게 챌린지가 추천된 이유에 대한 설명 / 건강 상태와 생활습관 변화의 비교·확인 / 더 간편하고 직관적인 사용 방식 / 기타(직접 입력)
11. 한 달 구독료가 얼마까지면 계속 쓰실 것 같나요? (필수) 한 달에 낼 수 있는 최대 금액이 속한 구간을 골라주세요. 무료일 때만 쓸 것 같아요 / 5,000원 미만 / 5,000원 이상 ~ 10,000원 미만 / 10,000원 이상 ~ 15,000원 미만 / 15,000원 이상
12. 무료라면 건강 업체 제휴 광고가 나와도 괜찮으신가요? 괜찮아요 / 상황에 따라 괜찮아요 / 불편해요
13. 하고 싶은 말이 있다면 적어주세요. (선택, 서술)

가격 구간의 근거와 해석 시 주의점은 `가격_시장조사.md`를 본다.

## 결과 사용 방침

- 응답 원본(개별 답, 주관식)은 저장소에 올리지 않는다. 주관식에 개인 정보가 섞일 수 있다.
- 저장소에는 개인정보가 없는 집계 숫자만 `결과_요약.md`로 남긴다.
- 서비스 수정은 항목별로 이슈를 열고 PR 하나씩 올린다.
