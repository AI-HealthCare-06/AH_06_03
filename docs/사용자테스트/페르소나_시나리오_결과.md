# 페르소나 시나리오 결과

> 서비스가 참여 정도와 건강 상태가 다른 사용자에게도 의도대로 동작하는지, 가상 사용자 몇십 명을 만들어 12주를 돌려 확인한 결과입니다. 191개 확인 항목이 모두 기대대로 나왔고, 서비스에서 확인할 점 다섯 가지가 드러났습니다.

## 1. 한눈에 보기

- **무엇을:** 가상 사용자로 12주(4주 × 3사이클)를 실제 서비스 API로 지나가게 했습니다.
- **결과:** 191개 확인 항목이 모두 기대대로 나왔습니다. 성실한 사용자는 완료, 참여가 적은 사용자는 미완료, 중간에 그만둔 사용자는 중단으로 처리됩니다.
- **드러난 점:** 가장 중요한 것은 "양호"가 위험 요인이 많은 사람에게도 나온다는 점입니다. 사용자가 "건강에 문제없다"로 오해할 수 있습니다.
- **결정:** 그대로 둘 것 셋, 지인 테스트 설문 결과를 보고 정할 것 둘로 정했습니다.
- **주의:** 화면 동작 확인용이며 실제 건강 개선 효과를 보여 주는 결과가 아닙니다.

## 2. 왜 했나

3차 멘토링에서 "다양한 페르소나 데이터를 케이스별로 만들어 12주를 했을 때 착실하게 한 사람과 제대로 안 한 사람의 결과를 확인하라"는 요청이 있었습니다. 체험단은 4주를 다 하지 않기 때문에, 실제 사용자 데이터 대신 가상 사용자로 12주를 미리 확인했습니다.

### 이 문서에서 쓰는 말

| 용어 | 뜻 |
|---|---|
| 사이클 | 4주짜리 챌린지 한 번입니다. 프로그램은 3사이클(12주)입니다. |
| 달성률 | 미션별로 한 주에 목표 횟수만큼 했는지를 4주 평균한 값입니다. 모든 미션이 80% 이상이어야 사이클이 "완료"입니다. |
| 완료 / 미완료 / 중단 | 4주를 목표대로 마침 / 목표에 못 미치고 마침 / 사용자가 중간에 그만둠 |
| 모델 A, "10년 내 심장 혈관 건강 신호" | 앞으로 10년 내 관상동맥질환 위험을 한국인 기준으로 보정해 추정한 확률입니다. 2% 미만이면 양호, 2–9%는 주의, 9% 이상은 높음입니다. |
| 모델 B | "혈압이 정상인 사람들과 닮은 정도"를 3단계(비슷한 편 / 조금 달라요 / 많이 달라요)로 보여 줍니다. |

## 3. 무엇을 했나

가상 사용자를 만들고, 시계를 하루씩 옮기면서 가입, 건강정보 입력, 분석, 챌린지 시작, 매일 기록, 중단, 4주 재입력을 실제 API로 호출했습니다. 기대값은 결과를 보기 전에 명세와 규칙으로 정해 두었습니다.

| 구분 | 내용 |
|---|---|
| 참여 정도 7유형 | 성실, 초반 10일만, 주말만, 저조했다가 재개, 8일 하고 중단, 가입만 함, 금연만 주 3일 실패 |
| 건강 상태 12유형 | 정상 혈압, 주의혈압, 고혈압전단계, 미진단 고혈압 범위, 고혈압 치료 중, 관상동맥질환 진단자, 연령 경계(만 31·32·70·71세) 등 |
| 4주 재입력 3가지 | 개선, 악화, 값 그대로 |
| 규모 | 가상 사용자 50명(사이클 106개) |

## 4. 결과

- **참여 정도별:** 성실형은 3사이클을 모두 완료하고, 12주를 마친 뒤 다시 시작하면 막힙니다. 초반 이탈형·주말형은 미완료, 중단형은 기록이 남은 채 중단으로 처리됩니다.
- **건강 상태별:** 모델이 계산하지 않는 대상(만 32–70세 밖, 관상동맥질환 진단자, 고혈압 진단·치료 중)이 규칙대로 제외되고, 위험 범주와 미션 추천도 규칙대로 나옵니다. 총콜레스테롤을 비우면 학습 데이터 중앙값 234로 대체한 결과와 같고 결과에 표시됩니다.
- **4주 전후 비교:** 같은 사람(50세 남성, 처음 혈압 135/85 · 체중 80kg · 흡연 중)이 4주 뒤 다시 입력했을 때 모델 A 확률이 개선하면 1.70%에서 0.98%로 내려가고, 악화하면 2.06%로 올라가며, 값이 같으면 1.70% 그대로입니다.
- **50명 규모:** 사용자별 상태와 관리자 통계(완료 38, 미완료 54, 중단 6, 진행 8)가 별도로 다시 계산한 값과 모두 일치했습니다.

유형별 상세 결과는 부록 A–C에 있습니다.

## 5. 발견과 결정

### 발견 1. "양호"가 건강 문제가 없다는 뜻으로 읽힐 수 있다

- **문제:** 50세 흡연·음주 남성이 혈압 135/85인데도 모델 A가 "양호"(1.70%)로 나옵니다. 같은 화면에서 모델 B는 "혈압이 정상인 사람들과 많이 달라요"를 보여 줍니다.
- **원인:** 양호는 "앞으로 10년 내 심장 혈관 질환 확률이 낮다"는 구간(2% 미만)입니다. 혈압이나 흡연 같은 위험 요인이 있어도 확률 자체는 낮게 나올 수 있습니다.
- **결정:** 지금은 화면을 바꾸지 않습니다. 지인 테스트 설문 4번("양호"를 어떻게 이해했는지)으로 오해 비율을 먼저 재고, 오해가 많으면 결과 화면에 "'양호'는 이 지표가 낮다는 뜻이지 건강을 보장하는 건 아니에요" 한 줄을 넣습니다. 설명을 먼저 넣으면 오해 비율을 정확히 잴 수 없기 때문입니다.

### 발견 2. 참여가 적은 사용자에게 나오는 안내 문구가 달성률과 상관없이 같다

- **문제:** 주 2일만 하거나 초반에만 하면 4주가 "미완료"로 끝납니다. 다시 들어오면 "다음 4주 시작하기"는 나오지만, 안내 문구는 달성률이 12%든 57%든 같은 한 줄입니다.
- **결정:** 지금은 바꾸지 않고, 설문 9번(계속 사용 의향) 결과를 보고 달성률에 맞게 문구를 나눌지 정합니다. 문구를 바꾸면 설문으로 재려는 값이 달라지기 때문입니다.

### 발견 3–5. 그대로 두기로 한 것

| 관찰 | 결정과 이유 |
|---|---|
| 금연 미션만 57%여도 나머지를 다 해도 4주 전체가 "미완료"가 된다 | 규칙은 유지합니다. 화면이 미션별 달성률과 "완료"를 따로 보여 주고, 관리자 통계와 보상이 이 기준 위에 있습니다. 지인 인터뷰에서 "미완료" 표시가 낙담된다는 반응이 나오면 표시만 "미션 3개 중 2개 달성"으로 바꿉니다. |
| 중간에 중단한 사용자는 4주 전후 비교를 볼 수 없다 | 유지합니다. "4주를 끝낸 챌린지"의 전후 비교가 의도이고, 다시 시작해 4주를 마치면 비교를 볼 수 있습니다. 대신 중단 이유가 저장되지 않고 있어서, 중단할 때 이유를 한 번 묻도록 추가합니다. |
| 4주 비교에서 확률이 1.70%에서 2.06%로 오르면 범주가 "양호"에서 "주의"로 바뀐다 | 유지합니다. 비교 화면이 혈압·체중·허리둘레의 실제 변화를 맨 위에 두고, 확률도 함께 보여 줍니다. |

## 7. 못 본 것과 한계

- 가상 사용자라서 실제 사람이 얼마나 이탈하는지는 지인 테스트로 확인해야 합니다.
- 화면은 일부 계정만 직접 열어 봤고(부록 E), 나머지는 서비스 규칙 수준의 확인입니다.
- 모델 A "높음"(9% 이상) 범주는 12개 건강 프로필에서 나오지 않아서, "높음이면 상담 배너가 뜬다"는 경로는 이번에 확인하지 못했습니다.
- 50명 규모의 속도는 로컬 환경 기준이라 실제 서버 성능은 별도로 확인해야 합니다.
- 배지와 파이 값은 보지 못했습니다.

### 부록 C. 4주 재입력 전후 비교

여기서 "확률"은 **모델 A의 "10년 내 심장 혈관 건강 신호" 확률**입니다. 앞으로 10년 안에 관상동맥질환이 생길 위험을 한국인 기준으로 보정해 추정한 값이고, 화면에는 "생활습관 관리용 참고 신호"로 표시됩니다. 범주는 이 확률로 정해집니다(2% 미만 양호, 2–9% 주의, 9% 이상 높음). 모델 B는 확률이 아니라 "혈압이 정상인 사람들과 닮은 정도" 3단계(비슷한 편 / 조금 달라요 / 많이 달라요)입니다.

비교한 사람은 모두 같은 인물입니다: **50세 남성, 175cm, 처음 입력값 혈압 135/85 · 체중 80kg · 허리둘레 90cm · 흡연 중 · 음주 주 2–3회(한 번에 5–6잔), 총콜레스테롤 190, 당뇨·고혈압 진단·가족력 없음.** 4주 뒤 다시 입력하는 값만 사례마다 다릅니다(나이·키·콜레스테롤 등은 처음 값을 그대로 씁니다).

| 사례 (4주 뒤 다시 입력한 값) | 모델 A "10년 내 심장 혈관 건강 신호" 확률 (처음 → 4주 뒤) | 모델 B 단계 (처음 → 4주 뒤) | 사이클 |
|---|---|---|---|
| R1 성실 + 개선 (혈압 124/78, 체중 76kg, 허리 84cm, 금연, 음주 월 1회) | 1.70% → 0.98% (둘 다 양호) | 많이 달라요 → 많이 달라요 | 완료 |
| R2 성실 + 악화 (혈압 148/92, 체중 85kg, 허리 96cm, 흡연 유지, 음주 주 4회 이상) | 1.70% → 2.06% (범주가 양호에서 주의로 넘어감) | 많이 달라요 → 많이 달라요 | 완료 |
| R3 참여 10일 + 값 그대로 (처음과 같은 값) | 1.70% → 1.70% (그대로) | 변화 없음 | 미완료, 재입력 가능 |

오류 경로도 확인했습니다.
- 같은 사이클에 두 번째 재입력은 `409 REASSESSMENT_DUPLICATED`
- 필수 항목(흡연) 누락은 `422 REASSESSMENT_INCOMPLETE`
- 아직 진행 중인 사이클에서는 `409 CHALLENGE_CYCLE_NOT_ENDED`
- **중도에 중단한 사용자는 `409 CHALLENGE_CYCLE_NOT_ENDED`로 재입력과 전후 비교를 할 수 없습니다.**

### 부록 D. 시연용 가상 계정 (로컬 전용, 팀 참고용)

화면으로 직접 확인하려고 만든 계정입니다. **내 컴퓨터의 로컬 서버(`serve_demo.py`)에만 있고, 실제 서비스 서버에는 없습니다.** 날짜는 "오늘" 기준으로 계산해서, 각 계정이 오늘 보면 설명한 상태로 보입니다. 로그인은 9개 모두 확인했습니다.

- 로그인 주소: `http://localhost:5500/login.html` (서버는 `serve_demo.py`가 8000번 포트로, 화면은 `team_snapshot_new/frontend`를 5500번 포트로 띄웁니다)

### 부록 E. 화면 확인 결과 (로컬 서버, 계정 1·2·9)

9개 계정 중 3개 계정의 화면을 실제로 열어 확인했습니다. 나머지 계정(3·4·5·6·7·8)과 관리자 화면은 아직 열어 보지 않았습니다.

| 계정 | 화면 | 확인된 내용 |
|---|---|---|
| 1 성실형 | 홈 | "12주 계획을 모두 마쳤어요", "12주 중 12주차 · 28 / 28일", 건강 신호 양호 1.7%, 혈관 나이(추정) 53세, "12주 결과 확인하기" 버튼 |
| 2 초반 열정형(10일만 기록) | 홈 | "12주 계획 1/3차가 끝났어요", "12주 중 4주차 · **28 / 28일**", "4주 결과 확인하기" |
| 2 초반 열정형 | 챌린지 | "1차 4주가 끝났어요 · 달성률 37%", "다음 4주 미션을 다시 골라요.", "4주 재입력하고 변화 보기" 버튼 |
| 9 악화 후 재입력 | 4주 비교 | 혈압 135/85 → 148/92, 체중 80 → 85kg, 허리 90 → 96cm, 미션 3개 모두 "100% · 완료", 흡연 현재 피움 → 현재 피움, 음주 주 2–3번 → 주 4번 이상, **건강 신호 양호(1.7%) → 주의(2.1%)**, 모델 B "비슷한 자리예요", "2차 챌린지 시작하기" 버튼 |

- 시뮬레이션 기대값(R2: 1.70% → 2.06%)과 4주 비교 화면의 표시가 일치합니다.
- **새로 확인된 점:** 10일만 기록한 계정 2의 홈에도 "28 / 28일"이 표시됩니다. 이 숫자는 기록한 날이 아니라 지나간 날짜 기준이라, 참여가 적은 사용자에게도 다 채운 것처럼 보일 수 있습니다. 지인 테스트가 끝난 뒤 문구를 정리할 때 "기록한 날" 병기를 함께 검토합니다.
