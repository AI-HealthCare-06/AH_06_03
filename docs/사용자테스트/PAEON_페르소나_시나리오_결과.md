# 가상 사용자(페르소나) 시뮬레이션 결과

3차 멘토링에서 "참여 정도가 다른 가상 사용자로 12주 결과를 확인하라"고 해서 돌린 결과입니다. 검증한 코드는 main 5f8d310이고, 저장소 코드는 바꾸지 않았습니다. **화면 동작 확인용이며 실제 건강 개선 효과를 보여 주는 결과가 아닙니다.** 191개 확인 항목이 모두 기대대로 나왔습니다.

## 1. 무엇을 돌렸나

- 참여 정도 7유형, 건강 상태 12유형, 4주 재입력 전후 비교 3가지, 50명 규모(사이클 106개)
- 시계를 하루씩 옮기며 실제 API로 가입, 분석, 챌린지 시작, 매일 기록, 중단, 재입력을 호출했습니다.
- 기대값은 결과를 보기 전에 명세와 규칙으로 정했습니다.

## 2. 결과

### 2-1. 참여 정도별 7유형 (12주 = 4주 × 3사이클)

| 유형 | 행동 | 결과 |
|---|---|---|
| 성실형 | 매일 기록 | 3사이클 완료. 12주를 마친 뒤 다시 시작하면 409 |
| 초반 열정형 | 첫 10일만 기록 | 1사이클 미완료(달성률 37%). 다시 시작 가능 |
| 주말형 | 토·일만 기록 | 3사이클 모두 미완료(32%) |
| 저조 후 재개형 | 첫 사이클 3일, 이후 매일 | 미완료 → 완료 → 진행 중 |
| 중도 중단형 | 8일 기록 후 중단 | 상태 stopped, 기록 보존, 다시 시작 가능 |
| 신규 가입형 | 기록 없음 | 진행 중 챌린지 조회 404, 추천 미션 조회 200 |
| 금연 실패 반복형 | 금연만 주 3일 실패 | 금연 미션만 미완료(57%), 사이클은 미완료 |

### 2-2. 건강 상태별 12유형

- 모델 A·B가 건너뛰는 조건이 명세대로 동작합니다. 모델 A는 만 32–70세 밖과 관상동맥질환 진단자, 모델 B는 고혈압 진단·치료 중입니다.
- 위험 범주(양호·주의·높음)가 모든 프로필에서 확률 기준(2% 미만 양호, 2–9% 주의, 9% 이상 높음)과 일치합니다.
- 미션 추천이 규칙대로입니다. 흡연자만 SMK-1, 3잔 이상 음주자만 ALC-1이 고정되고, 혈압 160/100 이상이면 ACT-3이 후보에서 빠집니다.
- 총콜레스테롤을 비우면 `missing_features`에 표시되고, 중앙값 234를 입력한 결과와 확률·혈관 나이가 같습니다.
- 위험 요인이 많을수록 확률이 높게 나옵니다.

### 2-3. 4주 재입력 전후 비교

"확률"은 모델 A의 "10년 내 심장 혈관 건강 신호" 확률입니다. 비교한 사람은 모두 같은 인물입니다: **50세 남성, 175cm, 처음 입력값 혈압 135/85 · 체중 80kg · 허리둘레 90cm · 흡연 중 · 음주 주 2–3회(한 번에 5–6잔)**.

| 사례 | 4주 뒤 다시 입력한 값 | 확률(처음 → 4주 뒤) | 범주 |
|---|---|---|---|
| 개선 | 혈압 124/78, 체중 76kg, 허리 84cm, 금연, 음주 월 1회 | 1.70% → 0.98% | 양호 → 양호 |
| 악화 | 혈압 148/92, 체중 85kg, 허리 96cm, 흡연 유지, 음주 주 4회 이상 | 1.70% → 2.06% | 양호 → **주의** |
| 값 그대로 | 처음과 같은 값 | 1.70% → 1.70% | 변화 없음 |

중단한 사용자가 재입력하거나 진행 중인 사이클에서 재입력하면 409(`CHALLENGE_CYCLE_NOT_ENDED`)가 나옵니다. 같은 사이클에 두 번째 재입력은 409(`REASSESSMENT_DUPLICATED`), 필수 항목(흡연)이 빠지면 422(`REASSESSMENT_INCOMPLETE`)입니다.

### 2-4. 50명 규모

사용자별 사이클 상태·달성률과 관리자 통계(완료 38, 미완료 54, 중단 6, 진행 8)가 별도로 다시 계산한 값과 모두 일치했습니다. 속도는 로컬 SQLite 기준이라 실제 서버 성능이 아닙니다.

## 3. 드러난 점과 결정

| 5 | 4주 비교에서 개선해도 모델 B 단계는 그대로이고, 악화는 확률이 1.70%에서 2.06%로 올라 범주가 "양호"에서 "주의"로 바뀐다 | 그대로 둔다. 비교 화면이 이미 실측 변화(혈압·체중·허리)를 맨 위에 두고 모델 A는 범주와 확률을 함께 보여 준다 |

## 5. 못 본 것

- 화면은 6절의 계정 3개만 실제로 열어 봤습니다. 시뮬레이션은 API 수준입니다.
- 모델 A "높음"(9% 이상) 범주는 12개 프로필에서 나오지 않아서, "모델 A 높음이면 상담 배너" 경로는 이번에 검증하지 못했습니다.
- 실제 서버(MySQL·EC2) 성능, 배지·파이 값은 보지 못했습니다.

9개 계정 중 3개 계정의 화면을 실제로 열어 확인했습니다. 나머지 계정(3·4·5·6·7·8)과 관리자 화면은 아직 열어 보지 않았습니다.

| 계정 | 화면 | 확인된 내용 |
