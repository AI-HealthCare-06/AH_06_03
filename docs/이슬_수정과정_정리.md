## 후보 1. 동의 철회 후 재수집 차단

**문제:** 건강정보 동의를 철회한 사람이 로그인이 남아 있다는 이유로 다시 입력·분석할 수 있으면 철회가 의미 없어요.

**흐름**
1. **철회 API 첫 구현 (10/8, 742d137):** 동의 정책·동의 철회 API를 만들고, 철회 상태에서 건강정보 API가 403을 주게 했어요. 동의 표(`consent_tables`)와 서비스(`consent_service`)를 추가했어요.
2. **화면 연결 (10/8):** 마이페이지의 동의 철회·다시 동의를 서버 API에 연결하고, 철회 상태에서 403이 나면 안내 배너와 마이페이지 링크를 보여 주게 했어요(3bba955). 철회·탈퇴 확인창도 넣었어요(3b62d24).
3. **문구 정리 (10/13, 10/20):** 철회하면 건강정보가 삭제된다는 안내를 정책 v4 문구에 맞췄고(d6dcaad), "철회하면 서비스를 이용할 수 없다"를 이용약관·처리방침·동의 화면·마이페이지에 명시했어요(06d0cc4).
4. **서버 차단 확대 (10/21, 혜림·효민):** 팀 결정(철회하면 모든 기능 차단)에 따라 커뮤니티·파이·캐릭터·공통 챌린지까지 막는 서버 코드와 시험이 들어갔어요(혜림 81cc929, 효민 b492f64, 혜림 fde2e59). *이 부분은 혜림님·효민님 작업이에요.*
5. **푸시 구독 정리 (10/23, 1bb2c18):** 알림을 만든 뒤 철회해도 이 브라우저에 구독이 남는 빈틈을 찾아, 철회할 때 브라우저 구독도 해제하고 재동의 뒤 알림 설정으로 안내하게 했어요.

**남길 근거:** 철회 전후 요청 결과(403), 위 수정 커밋, 회귀 시험(`tests/test_consent_withdrawn_blocks_all.py`, `test_common_challenge_consent.py`, `test_signup_consent.py`).

**이슬 몫을 정확히 쓰면:** 철회 API의 처음 구현과 화면·안내 문구, 알림 구독 정리. 재수집 차단을 서버 전 기능으로 넓힌 것은 혜림·효민.

## 후보 2. 모델 교체 후 과거 결과 보존

**문제:** 모델 버전이 바뀌면 이전 결과와 새 결과를 같은 기준으로 비교할 수 없어요. 버전만 저장해서는 "왜 이렇게 나왔는지" 설명이 안 돼요.

**이슬이 한 일 (화면·안내 쪽)**
- **10/13 (…):** 모델 A 버전이 바뀌어 비교할 수 없을 때, 오류가 아니라 "모델이 업데이트되어 이번에는 비교하지 않아요. 다음 4주부터 비교해요" 안내를 보이게 했어요.
- **10/22 (4주 비교 응답 중복 수정):** 4주 비교에서 모델 A·B가 두 번씩 나오던 문제를 고쳤어요(남은 반복문 제거).
- **10/22 (나이 고정 기준 수정, 9dd18b2):** 4주 재평가가 "맨 처음 예측"의 나이를 가져다 써서, 생년월일을 고친 계정의 4주 후 모델 A가 건너뛰어지던 문제를 "가장 최근 처음 예측" 기준으로 바꿨어요. 지인 배포 중 한 사용자 계정에서 확인한 오류예요.
- **10/22 (확률·혈관 나이 안내 분리, 혜성 초안):** 모델 A의 확률·혈관 나이·상위 %를 두 카드로 나누고 근거 문구를 각각 두어, 서로 다른 값을 섞어 읽지 않게 했어요.

**서버 쪽 버전 보존·재계산(`current_version_view`, 같은 버전끼리 비교)은 혜림님 작업이에요.** 이슬은 그 결과를 화면에 정확히 보이게 하는 부분을 맡았어요.

**남길 근거:** 구버전·신버전 결과 화면, 비교 불가 안내 문구, 나이 고정 기준 수정 전후(처음은 있고 4주 후만 빠지던 화면).

## 후보 3. 암호화와 복구

**이슬 몫은 "무엇을 어떻게 보호하는지"를 문서와 화면에 정확히 쓰는 것이었어요.**
- **10/14, 10/20, 10/21 (처리방침):** 디스크 암호화를 "적용할 예정"에서 "완료"로 맞추고, 서버 접속·배포 인원을 구분하고, 이메일을 컬럼 단위로 암호화해 저장하며 관리자 화면에는 마스킹해서 보인다고 정확히 적었어요.
- **보관·삭제 기간:** 건강정보는 삭제 후 백업에 최대 1주, 관리자 권한 이력 3년, 접속 기록 3개월, 관리자 행위 기록 2년을 표로 정리했어요.
- **관리자 화면에서 개인정보 노출 줄이기 (10/13~16):** 가입자 목록·상세, 테스트 계정 삭제를 만들 때 이메일 같은 값이 그대로 보이지 않게 했어요.

**암호화 구현·복구 절차(키 관리, 데이터 변환)는 혜림님·효민님 작업이에요.** 이슬은 보호 범위를 사실대로 쓰는 일을 맡았고, 확인하지 못한 것은 쓰지 않는다는 원칙을 지켰어요(예: 건강정보 전체 암호화 여부).
