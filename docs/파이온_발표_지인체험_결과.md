| 항목 | 내용 |
|---|---|
| 가입 | 26명 (건강정보 동의 전원) |
| 설문 응답 | 13명 (26명 중 50%), 20대 8·30대 4·40대 1 |
| 만족 | 계속 쓰고 싶음 8명(부정 0명), 추천 의향 NPS +15(참고용), 화면 속도 불편 0명, 제휴 광고 불편 0명 |

**한 줄 결론:** 결과 화면(혈관 나이, 상위 몇 %)은 재미있어 하지만, 매일 하는 챌린지가 부담이라 가장 많이 이탈했어요. 건강이 중요한 건 알지만 쓰기는 귀찮다는 결과예요.

## 1. 진행 퍼널 (관리자 화면 기준, 26명)

| 단계 | 인원 | 이전 단계 대비 이탈 |
|---|---|---|
| 가입 | 26 | — |
| 대상 확인 | 26 | 0 |
| 건강정보 입력 | 23 | 3 |
| 생활습관 설문 | 22 | 1 |
| 건강 분석 결과 | 22 | 0 |
| 챌린지 시작 | 19 | 3 |
| 다음 4주 시작 (두 번째 사이클) | 4 | — |

- 가장 많이 빠진 곳: **분석 결과 → 챌린지 시작(4명)**, 그다음 대상 확인 → 건강정보 입력(3명).
- 챌린지를 시작한 19명 중 3일 이상 기록한 사람 8명, 4주 결과를 받은 사람 7명, 새 12주 사이클을 시작하겠다고 한 사람 4명이에요(멘토링 때 브리핑한 집계. 중간 정리 문서에는 아직 미집계라 **발표 전에 `체험_집계.sql`로 숫자를 확인**해야 해요).
- 처음 올린 집계는 이메일 오타 중복 가입(`gmail.con`)을 포함한 27명 기준이라, 중복 1명을 빼고 다시 세어 26명으로 고쳤어요(수정 이력을 남김).
- 특이 사례 1명은 설문·분석 없이 챌린지를 시작한 것으로 기록됐어요.

## 2. 핵심 발견 (문제 → 근거 → 조치)

| 발견 | 근거 | 조치 | 상태 |
|---|---|---|---|
| **"양호"를 "건강에 문제없음"으로 오해** | 설문 5번: "양호"를 본 12명 중 **7명이 오해**, 5명 바르게 이해 | 양호일 때 배지 아래 안내 문구 추가(PR #198) | 배포됨. 배포 후 응답으로 **재확인 필요** |
| **챌린지를 3일 연속 이어가기 부담** | 3일 못 채웠다 5명(설문 3번), 시작 19명 중 11명이 첫 3일을 못 넘김 | 푸시 알림(10/23), 허들을 낮추는 방향은 향후 과제 | 향후 과제 |
| **혈압 입력에서 멈춤·헷갈림** | 직접 확인한 이탈자 3명 중 2명이 혈압 단계에서 멈춤, 수축기·이완기 입력란이 헷갈린다는 설문 의견 | 수축기·이완기를 "높은 쪽 혈압·낮은 쪽 혈압"으로 쉽게 표기(PR #207) | 반영됨 |
| **이메일 오타로 중복 가입** | 지메일 도메인 오타(`gmail.con`)로 같은 사람이 두 번 가입 | 이메일 뒷부분을 목록에서 선택(PR #207) | 반영됨 |
| **분석 없이 챌린지 시작 가능** | 설문·분석 없이 챌린지를 시작한 계정 1건 | 분석을 마치지 않으면 서버가 챌린지 시작을 막음(PR #206, ANALYSIS_REQUIRED) | 반영됨 |
| **병목 구간을 서버 분석 없이 보고 싶음** | 멘토님 요청, 지금은 DB 집계가 필요 | 관리자 화면에 **기간별 이탈 분석** 추가(PR #203, 효민) | 반영됨 |
| **유료 구독은 어렵고 무료 + 제휴 광고가 현실적** | 무료일 때만 사용 8명, 월 5,000원 미만 5명, 그 이상 0명. 광고 괜찮음 10·상황에 따라 3·불편 0 | 수익 모델을 무료 + 건강 업체 제휴 광고로 정리 | 정리됨 |
| **위험도 설명과 보상이 부족** | 가장 필요한 것(2개 선택): 보상 5·위험도 자세한 설명 5·간편한 사용 4·변화 비교 4·다양한 챌린지 4 | 결과 설명 보강, 보상(파이) 기획 | 일부 반영 |

## 3. 중도 탈락자 직접 확인 (3명, 설문 통계에는 섞지 않음)

| 구분 | 연령대 | 멈춘 곳 | 이유 |
|---|---|---|---|
| A | 40대 | 건강정보 입력(혈압) 전 | 혈압 수치를 몰라서 |
| B | 30대 | 건강정보 입력(혈압) 전 | 계속 입력하고 매일 뭔가 해야 하는 서비스라 어려울 것 같아서 |
| C | 40대 | 챌린지 시작, 기록 0일 | 해외여행으로 챌린지를 할 수 없었음 |

- 분석 결과를 보고도 챌린지를 시작하지 않은 4명은 익명 체험이라 이유를 확인하지 못했어요 → 다음에는 이유를 묻는 문항이 필요해요.

## 4. 만족 지표 (설문 13명)

| 지표 | 결과 |
|---|---|
| 계속 쓰고 싶음 | 매우 그렇다 3, 그렇다 5, 보통 5, 부정 0 → 긍정 8명 |
| 지인 추천 의향(0~10점) | 9~10점 4, 7~8점 7, 0~6점 2 → NPS +15 |
| 결과 화면을 본 생각 | 다음 4주도 해 보고 싶음 7, "가상 결과라 와닿지 않음"·"이해하기 어려움" 0 |
| 계속 쓰는 이유(복수) | 현재 건강 정보 확인 7, 장기 생활습관 기록 6, 전후 변화 확인 5, 미션 달성·보상 3, 커뮤니티 1 |
| 화면 속도 | 불편 0명 (전혀 없음 10, 한두 번 있었지만 괜찮음 3) |
| 막힌 곳(복수) | 없었음 7, 커뮤니티·파티 2, 그 외 각 1(가입·건강정보 입력·미션 기록·4주 비교 등) |

**긍정적인 발견:** 부정 응답 0명, 모델 A 결과를 병원의 혈관 나이 측정 시스템과 비교했을 때 같은 결과가 나왔다고 해요(지인 1~2명 확인).

## 5. 멘토님 반응과 정리 방향 (10/26 멘토링)

- 가설 "커뮤니티 기능이 리텐션을 높일 것"은 **실패**로 판단했어요(커뮤니티를 계속 쓰는 이유로 고른 사람 1명).
- 가장 큰 병목은 **초기 입력의 부담**과 **매일 하는 챌린지**예요.
- 멘토님 제안: 한 번에 다 묻지 않고 **정보를 점진적으로 모으는 방향**(가입 직후 1주일 챌린지를 하며 매일 조금씩 받기). 이번 프로젝트는 진입 장벽을 낮추고 데이터를 야금야금 모으는 방향으로 마무리하는 게 적절하다고 하셨어요.
- 건강 기능만으로 리텐션이 어려워서 포인트 보상(서울시 손목닥터처럼), 센서 연동 같은 적극 개입이 필요하다는 의견이었어요.
- 타겟을 좁히거나 명확히 하고, 소수 참여자 포커스 인터뷰를 해 보라고 하셨어요.
- 6주 동안 사용자 목소리를 직접 듣고 빠르게 고친 경험 자체를 긍정적으로 평가하셨어요.

## 6. 한계 (솔직하게)

- 설문 13명은 26명 중 일부이고 **20대에 치우쳐(8/13)** 있어요. 문제 발견용이며 통계적으로 해석하지 않았어요.
- 지인 대상이라 실제 사용자보다 우호적일 수 있어요. 커피 쿠폰을 줘도 10명 중 5명만 받아 갔어요.
- 30·40대 반응은 중도 탈락자 3명을 직접 만나 보완했어요.
- 분석 결과를 보고 챌린지를 시작하지 않은 4명의 이유는 확인하지 못했어요.
- 4주 결과는 미리 정해진 체험용 결과라서 결과 종류별 응답은 화면 반응으로만 해석했어요.
- 숫자 일부(3일 이상 기록 8명, 4주 결과 7명)는 `체험_집계.sql` 확인 전이에요.

## 7. 슬라이드 구성안 (제안)

1. 체험 개요: 기간, 대상, 방법(관리자 화면 집계 + 설문 + 직접 인터뷰)
2. 퍼널: 26명이 어디서 얼마나 빠졌는지(막대 그래프)
3. 핵심 발견 → 조치 표(위 2번에서 3~4개만)
4. 사례: "양호" 오해(발견 → 설문 7/12 → 수정 → 재확인)
5. 이탈 이유와 인사이트: 쓰고 싶은데 귀찮다 → 점진적 정보 수집 방향
6. 한계와 다음 단계: 타겟 좁히기, 센서 연동, 포커스 인터뷰

**준비해야 할 것**
- 관리자 화면 캡처(퍼널·기간별 이탈 분석): 와이어프레임의 A05는 가짜(목업) 데이터라 **실제 운영 데이터로 다시 캡처**해야 해요.
- "양호" 오해 재확인 숫자(배포 후 응답): 있으면 사례 4번에 전후 비교로 넣어요.
- 3일 이상 기록한 8명·4주 결과 7명을 `체험_집계.sql`로 확정.
