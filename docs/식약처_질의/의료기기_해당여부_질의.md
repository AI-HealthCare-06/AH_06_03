# 식약처 질의: 의료기기 해당 여부

안녕하세요.
생활습관 관리 및 개선에 도움을 주는 모바일웹서비스를 구상 중이며 아래 기능 구성이 의료기기에 해당하는지 먼저 확인하고 싶어 문의드립니다.

## 1. 사용목적

만성질환의 위험을 줄이는 데 도움이 되는 건강한 생활습관을 사용자가 꾸준히 실천하도록 돕습니다.
사용자는 금연, 절주, 나트륨 줄이기 같은 생활습관 개선 챌린지에 참여해 매일 실천 여부를 스스로 기록하며 건강한 루틴을 만듭니다. 질병의 진단·치료·예방, 의료진의 판단 보조, 복약 조절은 목적으로 하지 않습니다.

## 2. 주 사용대상

고혈압 진단을 받은 적이 없는 만 19세 이상 성인으로,
- 건강 루틴을 만들어 생활습관을 관리하고 싶은 사람
- 지금은 건강하지만 흐트러진 생활습관이 걱정되는 사람

\* 그 밖의 이용자: 고혈압 진단·치료 중인 성인도 생활습관 챌린지와 4주 기록 비교는 이용할 수 있습니다. 복약·치료 안내는 하지 않습니다.
\* 이용 제외: 만 19세 미만, 협심증·심근경색 등 관상동맥질환 진단자

## 3. 구조 및 사용방법

**구조**
- 웹 브라우저에서 동작하는 독립형 소프트웨어입니다.
- 측정 기능과 측정 기기와의 연동이 없습니다.
- 의료기관으로 데이터를 전송하지 않습니다.

**사용방법**
- Step 1. 사용자가 건강검진 결과와 가정에서 측정한 혈압값을 직접 입력합니다.
  입력 항목: 나이, 성별, 키, 체중, 허리둘레, 혈압, 총콜레스테롤(알고 있는 경우만 입력), 흡연, 음주, 당뇨 여부, 고혈압 진단·치료 여부, 고혈압 가족력, 생활습관 설문(나트륨 습관, 외식배달, 아침식사여부, 신체 활동)
- Step 2. 결과를 확인합니다.
- Step 3. 입력 항목을 바탕으로 추천받은 생활습관 개선 미션을 4주 단위로 매일 진행하고 기록합니다.
  (미션 종류: 금연, 절주, 스쿼트하기, 소금/간장 더 넣지 않기, 평소보다 2,000보 더 걷기 등)
- Step 4. 4주마다 "혈압·체중·허리둘레"를 다시 입력해 이전 값과의 변화를 확인한 후 기존 미션 또는 새로운 미션을 통해 생활습관 루틴을 만들어 갑니다.

## 4. 작용원리(기능별)

**① 심장혈관 건강신호**
공개 연구 자료(Framingham Heart Study)로 학습한 로지스틱 회귀식으로 10년 관상동맥질환 발생 확률을 계산하고 한국인 평균 발생률에 맞게 보정합니다.
- 입력값(9개): 나이, 성별, 수축기 혈압, 총콜레스테롤, BMI(키·체중), 현재 흡연 여부, 당뇨 여부, 고혈압 진단 여부, 혈압약 복용 여부
- 화면 표시사항: "10년 내 심장 혈관 건강 신호" 확률(%), 양호/주의/높음, 같은 성별·연령대 한국 성인 대비 상위 %, 혈관 나이(추정값)를 보여줍니다.
- 진단·발병 예측으로 표현하지 않고 "참고 신호"로 표시하며, 이 계산 결과는 미션 추천에 사용하지 않습니다.

**② 생활습관 유사도**
국민건강영양조사(2022~2024) 공개 자료로 학습한 로지스틱 회귀식으로, 혈압이 정상인 사람들과 사용자의 생활습관이 비슷한 정도를 계산합니다.
- 입력값(8개): 나이, 성별, BMI, 허리둘레, 부모의 고혈압 여부, 흡연(현재·과거), 음주 빈도, 한 번에 마시는 양
- 화면 표시사항: 숫자 없이, "지금 내 생활습관과 체형은 혈압이 정상인 사람들과 비슷한 편이에요 / 조금 달라요 / 많이 달라요"를 표시하고, 4주 비교 화면에서는 "4주 전보다 더 비슷해졌어요 / 비슷한 자리예요 / 조금 달라졌어요"로 표시합니다.

**③ 생활습관 미션**
사용자 입력값 중 "흡연·음주 응답, 생활습관 설문, BMI"로 미션을 추천합니다.
- ①, ②의 계산 결과를 미션 추천에 사용하지 않고, 사용자가 입력한 건강정보와 생활습관 설문 답변만을 바탕으로 추천합니다. 매일 실천 여부 체크, 4주 단위 기록의 변화를 비교하며 "진단"이나 '발병 예측"으로 표현하지 않습니다.
- 화면 표시사항: 매일 실천 여부 체크, 4주 단위 기록 비교

**④** 결과 화면에 모든 사용자에게 같은 주의 문구를 표시합니다: "본 제품은 질병 유무를 판단할 수 없으며, 질병 유무 판단을 위해서는 의사의 검진이 필요합니다."

## 5. 문의 사항

아래 두 가지 구성으로 나눌 경우, 각각의 의료기기/웰니스 구분 여부 관련해 답변해 주시면 큰 도움이 될 것 같습니다.
- 구성 A: 4번의 ② 생활습관·체형 유사도, ③ 생활습관 미션, ④ 주의 문구 (① 심장 혈관 건강 신호 제외)
- 구성 B: 구성 A + ① 심장 혈관 건강 신호
