## 1. 모델 A — Framingham (10년 내 관상동맥질환)

| 항목 | 내용 |
|---|---|
| 데이터 | Kaggle `framingham.csv` 4,240명 (미국 매사추세츠 주민, NHLBI 교육용 데이터의 1차 검사 ≈1956년) |
| 설계 | **코호트**: 같은 사람을 10년 추적 → "지금 값 → 10년 뒤 결과" |
| 라벨 | `TenYearCHD` = 10년 내 관상동맥질환 발생 **0/1** (협심증·심근경색·관상동맥 사망 포함). 3단계 라벨은 없음 |
| 발생률 | 15.2% (남 18.8% · 여 12.4%) |
| 나이 | 32–70세 → **이 범위 밖은 예측하지 않음** |
| 사용 피처 (9개) | 나이, 성별, 수축기혈압, 총콜레스테롤, 흡연, 당뇨, 혈압약 복용, 고혈압 진단, BMI |
| 빠진 입력 | **HDL** (데이터에 없음), **공복혈당** (이 데이터는 공복이 아닌 수시 혈당이라 한국 검진값과 다름) |

### 1.1 할 수 있는 말 / 하면 안 되는 말
| ✅ 가능 | ❌ 금지 |
|---|---|
| "10년 내 심혈관(관상동맥)질환 위험이 경계 수준이에요" | "10년 내 심혈관질환에 걸릴 확률 15%" (보정 전이라 수치가 부풀려짐) |
| "위험을 높인 요인 중 1위는 수축기혈압이에요" | "10년 뒤 고혈압이 생길 확률" (라벨이 고혈압이 아님) |
| "같은 조건의 사람들보다 위험이 높은 편이에요" | 진단·처방 표현 (NFR-SAFE) |

### 1.2 보정을 안 해서 생기는 일 (첫 번째 사이클 한계)
- 이 데이터의 10년 발생률은 남 18.8% · 여 12.4%이고, 한국인 코호트(Korean Heart Study)의 10년 위험은 **남 1.03% · 여 0.40%**임 → 한국 사용자에게 쓰면 위험이 크게 부풀려짐
- 첫 번째 사이클은 "입력 → 결과가 끝까지 돌아가는지" 확인이 목표라 보정 없이 연결함. 보정(한국인 기준 상대 위치 = 같은 성별·연령대 상위 %)은 다음 사이클
- 범주 구간(정상 <10% · 경계 10–20% · 위험 >20%)은 **데모 코드 기준을 그대로** 씀. 미국 데이터 기준으로는 잘 나뉨(§1.3)이지만, 한국 사용자는 경계·위험 쪽으로 쏠릴 수 있음

### 1.3 성능 (테스트 848명, 학습에 안 쓴 데이터)
| 모델 | 교차검증 AUC | 테스트 AUC | 비고 |
|---|---|---|---|
| **로지스틱회귀 (전달용)** | 0.731 ± 0.030 | **0.701** | |
| XGBoost (비교) | 0.710 ± 0.024 | 0.660 | 로지스틱보다 낮음 → 전달하지 않음 |

범주별 실제 발생률 (로지스틱, 테스트):
| 범주 | 인원 | 실제 10년 발생률 |
|---|---|---|
| 정상 (<10%) | 381 | 6.3% |
| 경계 (10–20%) | 259 | 17.8% |
| 위험 (>20%) | 208 | 28.4% |

→ 범주가 올라갈수록 실제 발생률도 올라감 (범주 표시가 의미 있음)

- "걸린다/안 걸린다" 0/1로 자르면(기준 50%) 테스트 848명 중 17명만 "걸린다"가 됨 (발생률이 15%라 확률이 50%를 넘는 사람이 드묾) → **0/1 대신 확률 + 범주로 제공**
- AUC 0.70 = 무작위로 뽑은 발생자·비발생자 쌍에서 발생자에게 더 높은 점수를 줄 확률이 70%

### 1.4 혈관 나이 (추정치)
- **학습한 값이 아니라** 모델 A 계수로 계산하는 후처리 환산식임 (`모델_연결_명세.md` §2.3)
- 기준 = 학습 데이터(미국 1950–60년대) 평균. 평균 수축기혈압 132 · 총콜레스테롤 237이라, 이보다 낮은 경우가 많은 한국 사용자는 혈관 나이가 **실제보다 젊게** 나오는 쪽으로 치우칠 수 있음 (추정)
- 나이 계수가 작아서(1세당 0.066) 값이 크게 움직임: 당뇨 하나 ≈ +11년. 테스트 T3(62세)는 계산값 약 92세 → 상한 90
- ✅ 가능: "혈관 나이(추정) 48세 — 실제 나이보다 높은 편이에요" / ❌ 금지: 혈관 나이를 실제 건강 나이·진단처럼 표현, 큰 차이를 단정적으로 강조
- 보정해도(전체 위험 수준을 내려도) 혈관 나이 식에는 절편이 안 들어가서 값이 바뀌지 않음 → 기준 집단(평균) 자체를 한국인으로 바꾸는 건 두 번째 사이클 과제

### 1.5 모델 A의 고혈압 진단자 처리
- PRD v1.8 REQ-ELIG-002: 고혈압 진단·치료 상태는 **예측 제외 조건이 아니라 입력**. 학습 데이터에도 고혈압 30.5%가 포함돼 있음
- `htn_status` → `prevalentHyp`(진단 있음), `BPMeds`(약 복용 중)으로 변환
- Framingham의 `prevalentHyp`는 "시작 시점 고혈압"(측정 포함)이고 서비스는 "자기보고 진단"이라 뜻이 완전히 같지는 않음 (추정: 미진단 고혈압 사용자는 위험이 조금 낮게 나올 수 있음)

## 2. 모델 B — 국민건강영양조사 2022–2024 (현재 경계군과 닮은 정도)

| 항목 | 내용 |
|---|---|
| 데이터 | 질병관리청 국민건강영양조사 제9기 원시자료 (`HN22~24_ALL.sav`) → 재추출 `KNHANES_2022_2024_selected.parquet` |
| 설계 | **횡단면**: 한 시점 조사. 같은 사람을 추적하지 않음 → **미래 예측 불가** |
| 라벨 | `HE_HP` 1(정상) → 0, 2(주의혈압)·3(고혈압전단계) → 1, 4(고혈압·혈압약 복용) → **학습 제외** (PRD REQ-PRED-009, NFR-ML-008) |
| 학습 대상 | 19세 이상 11,022명, 경계군 34.5% |
| 혈압 | **피처에서 제외** (라벨이 혈압으로 계산됨 → 넣으면 답을 보고 맞히는 셈) |
| 사용 피처 (9개, v0.2.0) | 나이, 성별, BMI, 허리둘레, 부모 고혈압 가족력, 현재 흡연, 과거 흡연, 음주 빈도, 한 번 음주량 (v0.1.0의 유산소 신체활동·아침 결식·외식·배달 빈도는 제외, 사유는 `생활습관_입력_가이드.md` 부록 A) |
| 예측 제외 | 19세 미만, **고혈압 진단·치료 중** (학습에 고혈압이 없으므로) |

### 2.1 할 수 있는 말 / 하면 안 되는 말
| ✅ 가능 | ❌ 금지 |
|---|---|
| "혈압 외 특징이 경계군인 사람들과 닮은 정도" | "앞으로 고혈압(경계군)이 될 확률" |
| "나와 비슷한 특징을 가진 한국인 중 경계군이 많아요" | "허리둘레 때문에 경계군이 됐어요" (인과 아님) |
| "관련이 가장 큰 요인은 허리둘레예요" | 모델 B 확률로 정상·경계·위험 **판정** (판정은 입력 혈압 규칙) |

### 2.2 성능 (테스트 2,200명)
| 모델 | 교차검증 AUC | 테스트 AUC | 무작위 분할 AUC |
|---|---|---|---|
| **로지스틱회귀 (전달용, v0.2.0)** | 0.739 ± 0.007 | **0.744** | 0.742 |
| XGBoost (비교, v0.2.0) | 0.752 ± 0.007 | 0.744 | 0.753 |
| (참고) 로지스틱회귀 v0.1.0, 12개 피처 | 0.739 ± 0.007 | 0.745 | 0.744 |

- 두 모델 성능이 사실상 같음 → 설명이 쉽고 데모에 계수만 넣으면 되는 **로지스틱회귀를 전달**
- **가족 단위 누수 점검**: 국민건강영양조사는 한 가구의 가족을 모두 조사함. 가족이 학습·테스트에 갈라지면 성능이 부풀 수 있어서 **조사구(psu) 단위로 분할**함 (학습 460개 · 테스트 115개 조사구, 겹침 0). 조사구 단위(v0.2.0 0.744)와 무작위 분할(0.742) 차이가 거의 없음 → 누수 영향은 작았음

### 2.3 요인별 영향 (v0.2.0 로지스틱, 1단위 증가당 오즈비 · 테스트 평균 |기여도| — 여기서 기여도는 모든 요인을 평균 기준으로 잰 모델 전체 중요도)
| 요인 | 오즈비 | 평균 기여도 | 방향 |
|---|---|---|---|
| 나이 (1세) | 1.04 | 0.58 (1위) | ✅ |
| 성별 남 | 2.07 | 0.35 | — |
| BMI (1) | 1.09 | 0.25 | ✅ |
| 허리둘레 (1cm) | 1.03 | 0.22 | ✅ |
| 한 번 음주량 (1단계) | 1.11 | 0.15 | ✅ |
| 부모 고혈압 가족력 | 1.37 | 0.15 | ✅ |
| 과거 흡연 (vs 비흡연) | **0.67** | 0.14 | ⚠️ 반대 |
| 현재 흡연 (vs 비흡연) | **0.78** | 0.06 | ⚠️ 반대 |
| 음주 빈도 (1단계) | 1.02 | 0.03 | ✅ |

- v0.1.0에 있던 외식·배달 빈도(오즈비 0.96, 반대), 유산소 신체활동(1.03, 반대), 아침 결식(1.00, 영향 없음)은 v0.2.0에서 뺌

### 2.4 ⚠️ 반대 방향 요인 — 현재 흡연 · 과거 흡연
- 모델 계산은 그대로 두고, 각 요인에 `direction_matches_expectation` 표시를 붙임 (`false` = 상식과 반대로 학습됨)
- 기여도 기준점: 있다/없다 요인은 "없음"(0), 숫자·단계 요인은 학습 데이터 평균 → 담배를 안 피우는 사람에게는 흡연 기여도가 0이라 "흡연"이 요인으로 나오지 않음
- 흡연자에게는 "현재 흡연: 있음 → 위험을 낮춤(−0.24)"이 계산됨 (`test_cases.json` T1)
- **화면 규칙 (확정): `direction_matches_expectation = false`인 요인은 요인 목록에 표시하지 않음.** v0.2.0에서 두 요인은 기여도가 항상 0 이하라 `top_risk_factor`·`top_modifiable_factor`로 뽑히지 않음
- 금연 챌린지 근거는 모델 A(`currentSmoker`)와 문헌 (`생활습관_입력_가이드.md` 부록 B-7)
- 이렇게 나온 이유: 흡연은 혈압보다 혈관 손상을 통해 관상동맥질환 위험을 높임(모델 A에서는 정상 방향) / 한 시점 조사에서 흡연자의 혈압이 비슷하거나 낮게 나오는 현상은 영국 국가조사에서도 보고됨 (Primatesta 등, *Hypertension* 2001) / 건강 문제를 알고 담배를 끊은 사람이 과거 흡연에 섞였을 수 있음 (추정). 자세한 설명은 `생활습관_입력_가이드.md` 부록 A-2

## 3. 두 모델 공통

| 항목 | 내용 |
|---|---|
| 결측 처리 | 선택 항목이 비면 학습 데이터 중앙값으로 채워 예측하고 `missing_features`에 이름을 돌려줌 → 화면에 "정확도 한계" 표시 (PRD REQ-HEALTH-002) |
| 일관성 | 같은 입력이면 같은 결과. 100건 × 10회 반복 편차 0 확인 (NFR-ML-005) |
| 학습 ↔ 서비스 일치 | ① 변환표: 학습 데이터 행을 서비스 입력 형식으로 바꿔 predict에 넣은 확률 = 학습 코드로 바로 계산한 확률 (차이 최대 5×10⁻⁷, A 985건 · B 2,000건) ② 계수 저장: 학습된 sklearn 모델 확률 vs JSON 계수로 계산한 확률 차이 최대 1×10⁻⁵ (A 테스트 848건 · B 2,200건, 계수를 소수 6자리로 저장해서 생기는 반올림 차이) |
| 버전 | 모든 결과에 `model_version` 포함. 전·후 비교는 같은 버전끼리만 (NFR-ARCH-004) |
| 재현 | `modeling/model_a/train_model_a.py`, `modeling/model_b/train_model_b.py`, 검증 `modeling/verify_models.py`. 데이터는 저장소에 없음 → 환경변수 `PAEON_DATA_DIR`로 위치 지정 |
