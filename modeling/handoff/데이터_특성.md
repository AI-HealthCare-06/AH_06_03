## 1. 모델 A — Framingham (10년 내 관상동맥질환)

| 항목 | 내용 |

| 데이터 | Kaggle `framingham.csv` 4,240명 (미국 매사추세츠 주민, NHLBI 교육용 데이터의 1차 검사 ≈1956년) |
| 설계 | **코호트**: 같은 사람을 10년 추적 → "지금 값 → 10년 뒤 결과" |

| 발생률 | 15.2% (남 18.8% · 여 12.4%) |
| 나이 | 32–70세 → **이 범위 밖은 예측하지 않음** |
| 사용 피처 (9개) | 나이, 성별, 수축기혈압, 총콜레스테롤, 흡연, 당뇨, 혈압약 복용, 고혈압 진단, BMI |

### 1.1 할 수 있는 말 / 하면 안 되는 말
| ✅ 가능 | ❌ 금지 |
|---|---|
| "10년 내 심장 혈관 건강 신호 1.5% — 양호 수준이에요" (v0.2.0 보정 확률, 참고용) | "10년 내 심혈관질환에 걸릴 확률 1.5%" (질병 발생 예측·진단 표현. 보정 전 v0.1.1 값 15%는 부풀려져 있었음) |
| "위험을 높인 요인 중 1위는 수축기혈압이에요" | "10년 뒤 고혈압이 생길 확률" (라벨이 고혈압이 아님) |
| "같은 조건의 사람들보다 위험이 높은 편이에요" | 진단·처방 표현 (NFR-SAFE) |

### 1.2 보정을 안 해서 생기는 일 (v0.1.1, 첫 번째 사이클 한계 — 기록용)
> ※ 이 소절은 모델 A **v0.1.1(보정 전)** 기준 설명이다. v0.2.0에서 보정·범주 기준·혈관 나이 기준이 바뀌었으니 §1.6·§1.7을 볼 것.
- 이 데이터의 10년 발생률은 남 18.8% · 여 12.4%이고, 한국인 코호트(Korean Heart Study)의 10년 위험은 **남 1.03% · 여 0.40%**임 → 한국 사용자에게 쓰면 위험이 크게 부풀려짐
- 첫 번째 사이클은 "입력 → 결과가 끝까지 돌아가는지" 확인이 목표라 보정 없이 연결함. 보정(한국인 기준 상대 위치 = 같은 성별·연령대 상위 %)은 다음 사이클
- 범주 구간(정상 <10% · 경계 10–20% · 위험 >20%)은 **데모 코드 기준을 그대로** 씀. 미국 데이터 기준으로는 잘 나뉨(§1.3)이지만, 한국 사용자는 경계·위험 쪽으로 쏠릴 수 있음

### 1.3 성능 (테스트 848명, 학습에 안 쓴 데이터)
| 모델 | 교차검증 AUC | 테스트 AUC | 비고 |
|---|---|---|---|
| **로지스틱회귀 (전달용)** | 0.731 ± 0.030 | **0.701** | |
| XGBoost (비교) | 0.710 ± 0.024 | 0.660 | 로지스틱보다 낮음 → 전달하지 않음 |

범주별 실제 발생률 (로지스틱, 테스트):
| 범주 | 인원 | 실제 10년 발생률 |
|---|---|---|
| 정상 (<10%) | 381 | 6.3% |
| 경계 (10–20%) | 259 | 17.8% |
| 위험 (>20%) | 208 | 28.4% |

→ 범주가 올라갈수록 실제 발생률도 올라감 (범주 표시가 의미 있음)

- "걸린다/안 걸린다" 0/1로 자르면(기준 50%) 테스트 848명 중 17명만 "걸린다"가 됨 (발생률이 15%라 확률이 50%를 넘는 사람이 드묾) → **0/1 대신 확률 + 범주로 제공**
- AUC 0.70 = 무작위로 뽑은 발생자·비발생자 쌍에서 발생자에게 더 높은 점수를 줄 확률이 70%

### 1.4 혈관 나이 (추정치)
- **학습한 값이 아니라** 모델 A 계수로 계산하는 후처리 환산식임 (`모델_연결_명세.md` §2.3)
- **v0.2.0 기준 = 같은 성별·연령대 한국 성인(국민건강영양조사 2022~24, 가중) 평균** (`model_a_v0.2.0.json`의 `vascular_age.ref_means`). 위험요인이 한국 평균이면 혈관 나이 = 실제 나이
- (v0.1.1 기준은 학습 데이터(미국 1950–60년대) 평균이었음. 평균 수축기혈압 132 · 총콜레스테롤 237이라 한국 사용자는 **실제보다 젊게** 나오는 쪽으로 치우쳤음)
- 나이 계수가 작아서(1세당 0.066) 값이 크게 움직임: 당뇨 하나 ≈ +11년. 테스트 T3(62세)는 계산값 약 92세 → 상한 90
- ✅ 가능: "혈관 나이(추정) 48세 — 실제 나이보다 높은 편이에요" / ❌ 금지: 혈관 나이를 실제 건강 나이·진단처럼 표현, 큰 차이를 단정적으로 강조
- 절편은 혈관 나이 식에 들어가지 않으므로 확률 보정만으로는 값이 바뀌지 않음 → v0.2.0에서 기준 집단(평균)을 한국 성인으로 바꿈. 한국인 결과 자료로 검증한 값은 아님 (§1.8)

### 1.5 모델 A의 고혈압 진단자 처리
- PRD v1.8 REQ-ELIG-002: 고혈압 진단·치료 상태는 **예측 제외 조건이 아니라 입력**. 학습 데이터에도 고혈압 30.5%가 포함돼 있음
- `htn_status` → `prevalentHyp`(진단 있음), `BPMeds`(약 복용 중)으로 변환
- Framingham의 `prevalentHyp`는 "시작 시점 고혈압"(측정 포함)이고 서비스는 "자기보고 진단"이라 뜻이 완전히 같지는 않음 (추정: 미진단 고혈압 사용자는 위험이 조금 낮게 나올 수 있음)

### 1.6 모델 A 한국인 보정 — 근거와 한계 (v0.2.0)
- 상태: 서비스(`main`)의 모델 A는 v0.1.1이고 **보정이 없음**. 아래는 팀 저장소 밖 개인 폴더 `PAEON_모델A_보정`(2026-10-07 작성, `calibrate_model_a.py`·`kr_position.py`·`out/`)의 실험 결과와 그 근거 정리임. 이 실험을 바탕으로 **모델 A v0.2.0**(`model_a/artifacts/model_a_v0.2.0.json`, 생성 스크립트 `model_a/build_model_a_v020.py`)을 만들었음: 계수·입력은 v0.1.1 그대로, ① 성별 절편을 Jee 2014 본문의 평균 10년 위험(남 1.03% · 여 0.40%)에 맞춤 ② 같은 성별·연령대 한국 성인 상위 %(`percentile`)를 참고 정보로 제공 ③ 혈관 나이 기준 평균을 국민건강영양조사 성별×연령대 평균으로 변경 ④ **범주(양호/주의/높음)는 보정된 10년 위험의 절대 기준(JAS 2017: 2%·9%)** — 근거는 §1.7. (아래 표의 "실험"은 절편 목표를 1.20%·0.52%로 계산한 10/7 실험 값이고, v0.2.0은 1.03%·0.40%를 씀)

> **기록 문구 (그대로 인용할 것)**: 모델 A의 재보정은 D'Agostino 2001(JAMA 286:180)의 재보정 개념(계수는 유지, 위험요인 평균과 기저 발생률을 대상 집단 값으로 교체)을 로지스틱 절편에만 적용한 실험이다. 한국인 목표값(위험요인 평균, 발생률)은 Jee 2014(BMJ Open 4:e005025, Korean Heart Study)의 Table 1·2에서 가져왔다. Jee 2014 자체도 Framingham을 한국인에 재보정했으며, 우리 방식은 그 논문의 방법과 같지 않다. 한국인 결과 자료로는 검증하지 않았다.

**실험이 한 두 가지**
1. **한국인 상대 위치 (상위 %)**: 국민건강영양조사 2022~24, 만 32~70세 10,652명(가중)에 모델 A를 적용해 성별 × 연령대(32–39·40–49·50–59·60–70) 8개 그룹별 선형합(z) 분위수 1~99 표를 만듦 (`model_a_kr_percentile_v0.1.json`). 순위만 쓰므로 절편·목표 발생률과 무관
2. **절편 재보정**: 계수는 그대로 두고 성별 절편만 바꿈 (`model_a_kr_recal_v0.1.json`). 남 −1.98072 → −4.285528, 여 → −4.460877. 기준: Jee 2014 Table 1 평균 프로필에서의 위험 = 목표 10년 위험

**D'Agostino 2001과의 대조** — 발상(계수 유지, 위험요인 평균·기저 발생률 교체)은 같으나 **같은 방법은 아님**. "D'Agostino 2001의 방법을 그대로 따랐다"고 쓰지 말 것

|---|---|---|
| 모델 | 성별별 Cox 모델 | 로지스틱 1개 (Kaggle Framingham 4,240명), 성별 절편만 따로 |
| 결과 | 관상동맥 사망 + 심근경색 (hard CHD) | 모델은 협심증 포함 `TenYearCHD`로 학습, 목표값은 hard CHD |
| 기간 | 5년 | 10년 |
| 대상 집단 값 | 각 코호트 개인 자료 | Jee 2014 논문 표 (집계 값) |
| 보정 뒤 검증 | 코호트의 실제 사건과 비교 | 한국인 결과 자료가 없어 검증하지 못함 |

**Jee 2014 (KHS) 표 확인 결과** (원문 Table 1·2 직접 확인): 남/여 평균 나이 45.8/47.6, 수축기혈압 123.3/121.0, 총콜레스테롤 194.5/195.1, BMI 23.8/23.2, 현재 흡연 53.0%/5.1%, 당뇨 8.4%/6.0%, 고혈압 진단 28.6%/24.7%, 혈압약 4.4%/5.3%. hard CHD 2,086건·510건, 발생률 **121.1·52.1명 / 10만 인년**. 결과는 심근경색·돌연사·기타 관상동맥 사망(**협심증 제외**), 암·간질환·심혈관 질환·호흡기 질환 보고자 제외. 실험이 쓴 값은 모두 원문과 일치

- **1.03% (남) · 0.40% (여)**: 결과 문단의 "평균 10년 위험(average 10-year risk)". 이 수치의 산출 방식을 설명한 문장은 전문에 없음. 다만 Methods에 "1996~2001 기준선, 2011년 12월까지 추적해 **모든 대상자가 최소 10년 추적 가능**하도록 10년 CHD 위험 모델을 만들었다"고 적혀 있어, 첫 10년 위험으로 해석하는 것이 설계와 맞음 (**해석은 추정**)
- **1.20% (남) · 0.52% (여)**: 10/7 실험이 Table 2 발생률(남 121.1 · 여 52.1 / 10만 인년, 2,086건 · 510건)로 `1 − e^(−발생률 × 10)`을 계산한 값. 발생률은 추적 전체(중앙값 11.6년)의 평균이라, 나이가 들수록 위험이 커지는 후반부가 섞여 첫 10년 위험보다 높게 나올 수 있음
- v0.2.0은 **1.03% · 0.40%**를 씀 (논문이 직접 "10년 위험"이라고 쓴 값 + 모든 대상자가 10년 추적된 설계). 둘의 차이는 남 1.17배, 여 1.30배이며 Jee 2014 안에서 생기는 차이임

**협심증 정의 차이의 영향**

- 영향: ① 보정한 절대 수준이 "협심증을 뺀 범위"로 줄어든 척도가 됨 ② 계수는 협심증을 포함한 정답으로 배운 것이라 hard 사건에 그대로 맞는지 알 수 없음 (한국인 결과 자료가 없어 크기를 추정할 수 없음)
- 참고: 미국 그대로의 모델은 KHS 평균 프로필에서 남 10.9% · 여 5.9%를 내 목표(1.20%·0.52%)의 9.0배·11.3배임. Jee 2014가 보고한 공개 Framingham 함수의 3~6배보다 큼 (협심증 포함·1950년대 자료·10년 기준이 겹친 결과로 **추정**, 원인 분해는 하지 못함)

### 1.7 모델 A 범주(양호/주의/높음) 기준 — 왜 JAS 2017이고 왜 ATP III가 아닌가
**결론 (v0.2.0)**: 범주는 보정된 10년 위험 `probability`로 정한다. **양호 < 2% · 주의 2% 이상 ~ 9% 미만 · 높음 ≥ 9%** (JAS 2017의 low · moderate · high 구간). 같은 성별·연령대 상위 %(`percentile`)는 범주에 쓰지 않고 참고 정보로만 둔다. 코드 값(`normal`/`borderline`/`high`)은 그대로.

| 기준 | 구간 | 한국 성인(국민건강영양조사 2022~24, 만 32~70세, 가중, 보정 후 확률)에 적용 시 양호·낮음 / 주의·중간 / 높음 |
|---|---|---|
| NCEP ATP III (미국) | <10% / 10~20% / >20% | 남 98.0 / 2.0 / 0.0 · 여 100 / 0 / 0 · 전체 99.0 / 1.0 / 0.0 |
| **JAS 2017 (일본)** | **<2% / 2~9% / ≥9%** | **남 63.6 / 33.7 / 2.7 · 여 90.2 / 9.8 / 0.0 · 전체 77.1 / 21.6 / 1.4** |

**확인 방식**: 아래 인용은 모두 원문 텍스트를 직접 내려받아 읽고 확인한 것이다(ATP III = NHLBI *ATP III Executive Summary* PDF, JAS 2017 = Europe PMC 공개 전문 PMC6143773, Suita 원논문 = J-STAGE PDF, Jee 2014 = PMC4039825 전문, 대한지질동맥경화학회 지침 = lipid.or.kr PDF). 읽지 못한 것은 "확인하지 못함"으로 적었다.

**A. NCEP ATP III (미국)를 쓰지 않는 이유**
- 이 기준은 원래 **콜레스테롤 치료 강도를 정하는 분류**임. 가장 위험한 범주는 관상동맥질환과 그 동등 위험(10년 위험 >20%, 당뇨·말초동맥질환 등 포함), 다음은 위험요인 2개 이상이면서 10년 위험 ≤20%(10~20% / <10%로 다시 나눔), 마지막은 위험요인 0~1개이고, LDL 목표는 범주별로 100 / 130 / 160 mg/dL. 위험요인이 2개 이상인 사람에게만 Framingham 점수표로 10년 위험을 계산하고, 위험요인 0~1개는 "거의 모두 10년 위험 <10%"라 계산하지 않음
- 위험 점수의 결과는 **"심근경색과 관상동맥 사망(hard CHD)"**이며 협심증을 뺀 값. 요인은 나이·총콜레스테롤·HDL·수축기혈압·혈압약·흡연 (Framingham 연구 기반)
- **한국인에게 쓸 수 없는 이유** ① 한국인 발생률이 훨씬 낮음: Jee 2014 (Korean Heart Study)의 평균 10년 위험 남 1.03% · 여 0.40%로 ATP III 최저 구간(10%)의 1/10 수준 ② 같은 논문에서 Framingham 점수는 한국인 CHD 사건을 3~6배(전체 약 6배) 많이 예측함 ③ **일본 동맥경화학회(JAS 2017)도 같은 이유로 ATP III의 ≥20%를 쓰지 않았다**: "미국의 ATP III는 Framingham 점수로 10년 치명적 CAD·비치명적 MI 위험 ≥20%를 고위험으로 봤지만, ASCVD의 종류와 발생률이 미국과 달라 일본에서는 쓸 수 없다" (JAS 2017 본문) ④ 우리 계산: 보정 **전** 모델(v0.1.1)에 이 구간을 쓰면 한국 성인의 경계 이상이 남 63.1% · 여 37.2%(과대), 보정 **후** 확률에 쓰면 10% 이상이 남 2.0% · 여 0.0%뿐이라 **둘 다 사람을 구분하지 못함**. 10%/20%는 미국 치료 결정용 값이라는 한계도 있음

**B. JAS 2017 (일본 동맥경화학회)를 쓰는 이유와 근거** — *Japan Atherosclerosis Society (JAS) Guidelines for Prevention of Atherosclerotic Cardiovascular Diseases 2017*, J Atheroscler Thromb 2018;25(9):846- (doi:10.5551/jat.GL2017, 공개 전문 PMC6143773)
- **구간 값 (지침 본문)**: Suita 점수 ≤40 = low(10년 CAD 발생 확률 **<2%**), 41~55 = moderate(**2~8%**), ≥56 = high(**≥9%**). 같은 구간을 Sata 등(J Atheroscler Thromb 2021, PMC8629702)도 "2%~9%", "≥9%"로 인용해 교차 확인함
- **구간을 정한 방식 (지침 본문)**: "위험 등급의 임계값은 절대 위험으로 **통계적으로 정할 수 없어 임상적 합의와 사회적 관습**에 따랐다". 2012판(NIPPON DATA80 기반)의 범주 I·II·III과 **일관성을 유지**하도록 맞췄고, 두 개 다른 인구에서 low·moderate·high 분포가 2012판 범주와 거의 같음을 위원들이 확인했다고 적음
- **왜 Suita 점수인가 (지침 본문)**: 2012판의 NIPPON DATA80은 스타틴이 없던 시기 조사이고 결과가 사망이며 LDL·HDL 정보가 없어서, 체계적 문헌 검토에서 CAD 발생을 결과로 쓴 Suita 연구가 가장 적합하다고 판단함
- **JAS가 적은 한계 (지침 본문)**: Suita 점수의 절대 위험이 일본 전체를 대표하는지는 의문이고, 다른 지역 코호트보다 **절대 위험이 훨씬 높게 나올 수 있으며**, Suita는 관상동맥 중재술을 결과에 포함함. 당뇨·만성콩팥병·비심인성 뇌경색·말초동맥질환은 점수를 계산하기 전에 고위험으로 분류하고, 조기 CAD 가족력이나 내당능장애는 5점을 더함
- **Suita의 결과 정의 (Nishimura 등, J Atheroscler Thromb 2014;21(8):784-798 원문 Methods)**: 확정 또는 가능한 급성심근경색(MONICA 기준), 증상 발현 24시간 이내의 심장 돌연사, 또는 관상동맥 우회술·혈관성형술로 이어진 CHD. **협심증은 목록에 없음**(명시적으로 "제외한다"는 문장은 없음). 같은 논문: 건강한 일본인 5,521명, 평균 11.8년 추적, CHD 213건, **"Framingham 점수와 재보정한 Framingham 점수 모두 일본인의 10년 CHD 위험을 과대 추정했다"**
- **우리가 이 기준을 고른 이유**
  1. 발생률이 낮은 **동아시아** 인구에서 쓰는 10년 **절대 위험** 구간이고, JAS가 ATP III를 못 쓰는 이유(질환 종류·발생률 차이)를 직접 밝힘
  2. 결과 정의가 같은 계열: ATP III(심근경색 + 관상동맥 사망), Suita(심근경색 · 심장 돌연사 · 재관류), Korean Heart Study(심근경색 · 돌연사 · 기타 관상동맥 사망) 모두 **협심증을 포함하지 않음**. 우리 보정 목표(Korean Heart Study hard CHD)와 같은 계열
  3. 한국 성인 분포에 적용했을 때 세 구간이 모두 나뉨(위 표)
  4. 확률(%)을 화면에 보여줄 때 숫자와 범주가 어긋나지 않음 (상위 % 기준으로 나누면 "약 0.94%"에 "주의"가 붙는 문제가 있었음)
- **한국 자체의 10년 위험 % 구간은 없음 (대한지질동맥경화학회 지침 직접 확인)**: *Korean Guidelines for the Management of Dyslipidemia 5th*는 10년 위험 %가 아니라 **질환 · 당뇨 · 주요 위험요인 개수**로 분류함(주요 위험요인 ≥2 중등도, ≤1 저위험; LDL 목표 <55 / <70 / <100 / <130 / <160 mg/dL). 주요 위험요인: 나이(남 ≥45, 여 ≥55), 조기 ASCVD 가족력, 고혈압, 흡연, 낮은 HDL(<40)

**한계 (화면·문서에서 숨기지 않을 것)**
- JAS 구간은 **일본 Suita 점수 기준이고 임상 합의·관습으로 정한 값**이며, 우리 모델이나 한국인 결과 자료로 검증한 구간이 아님
- Suita는 재관류를 포함하고 Korean Heart Study의 hard CHD는 포함하지 않아 **결과 정의가 완전히 같지는 않음**. 우리 모델의 학습 정답(`TenYearCHD`)은 협심증을 포함함(§1)
- JAS는 당뇨 등이 있으면 점수와 무관하게 고위험으로 보지만 **우리 범주는 확률만으로 정함**(당뇨는 확률 계산의 입력 요인으로만 반영)
- 보정 확률은 추정치(§1.6)라 **경계(2%·9%) 근처의 사용자는 범주가 바뀔 수 있음**. 한국 여성은 발생률이 낮아 "높음"이 거의 없음(0.0%)
- 상대 위치(상위 %)로 범주를 나누는 방법은 임상·문헌 근거를 찾지 못해 쓰지 않음
- **확인하지 못한 것**: JAS 지침의 Suita 점수→확률 변환 그림(Fig. 2) 자체(본문 설명만 읽음), 한국인 위험식(KRS)의 점수표·절편(Jee 2014 본문에 없음)

| **한계 3 — 결과 정의** | 학습 정답(`TenYearCHD`)은 협심증을 포함하고, 목표값(Jee 2014)은 협심증을 제외한 hard CHD. 범주 기준 JAS(Suita)는 재관류를 포함 → 정의가 서로 완전히 같지 않음 (§1.7) |
| **한계 4 — 범주 기준** | JAS 2%·9%는 일본 기준이고 임상 합의·관습으로 정한 값. 이 모델·한국인 자료로 검증하지 않음. 경계 근처 사용자는 범주가 바뀔 수 있고, 한국 여성은 "높음"이 거의 없음(0.0%) |
| **한계 5 — 고위험 조건** | JAS는 당뇨 등이 있으면 점수와 무관하게 고위험으로 보지만 우리 범주는 확률만으로 정함 |
| **한계 6 — 입력** | HDL·공복혈당 없음. 고혈압 "진단"은 자기보고라 Framingham 정의와 완전히 같지 않음(§1.5). 입력이 비면 중앙값으로 채움 |
| **화면 필수 안내** | "일본 동맥경화학회 기준을 참고한 구간이며 한국인 자료로 검증된 진단 기준이 아닙니다. 의학적 진단·치료를 대신하지 않습니다." 목적은 "생활습관 관리용 참고 신호" (의료기기법은 질병 진단·치료·예방 **목적**으로 판단하므로 병명·진단·치료 지시 표현 금지) |
| **다음 버전 과제** | ① 한국인 결과 자료로 검증·재보정 (한국 코호트 개인자료 또는 한국인 위험식 KRS의 점수표 확보 — Jee 2014 본문에는 없음) ② 범주 기준을 한국 자료로 검증하거나 한국 지침 근거로 교체 ③ 당뇨 등 고위험 조건을 점수와 별개로 반영 ④ 학습 정답에서 협심증을 빼 목표 정의와 맞추기 ⑤ 입력 확대(HDL 등) ⑥ 모델 B 재학습·모델 A 보정 보강은 `docs`의 "다시 생각해볼 내용" 목록과 함께 관리 |
| **확인하지 못한 것** | D'Agostino 2001 본문 수식(초록·2차 자료만 확인), JAS 지침의 Suita 점수→확률 변환 그림(Fig. 2), 한국인 위험식(KRS) 점수표, 식약처 판단기준 원문(뉴스 요약으로 확인) |

### 2.4 ⚠️ 반대 방향 요인 — 현재 흡연 · 과거 흡연
- 모델 계산은 그대로 두고, 각 요인에 `direction_matches_expectation` 표시를 붙임 (`false` = 상식과 반대로 학습됨)
- 기여도 기준점: 있다/없다 요인은 "없음"(0), 숫자·단계 요인은 학습 데이터 평균 → 담배를 안 피우는 사람에게는 흡연 기여도가 0이라 "흡연"이 요인으로 나오지 않음
- 흡연자에게는 "현재 흡연: 있음 → 위험을 낮춤(−0.24)"이 계산됨 (`test_cases.json` T1)
- **화면 규칙 (확정): `direction_matches_expectation = false`인 요인은 요인 목록에 표시하지 않음.** v0.2.0에서 두 요인은 기여도가 항상 0 이하라 `top_risk_factor`·`top_modifiable_factor`로 뽑히지 않음
- 금연 챌린지 근거는 모델 A(`currentSmoker`)와 문헌 (`생활습관_입력_가이드.md` 부록 B-7)
- 이렇게 나온 이유: 흡연은 혈압보다 혈관 손상을 통해 관상동맥질환 위험을 높임(모델 A에서는 정상 방향) / 한 시점 조사에서 흡연자의 혈압이 비슷하거나 낮게 나오는 현상은 영국 국가조사에서도 보고됨 (Primatesta 등, *Hypertension* 2001) / 건강 문제를 알고 담배를 끊은 사람이 과거 흡연에 섞였을 수 있음 (추정). 자세한 설명은 `생활습관_입력_가이드.md` 부록 A-2
