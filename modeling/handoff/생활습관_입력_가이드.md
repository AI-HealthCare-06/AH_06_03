## 1. 최초 입력

### 1.1 W04 건강정보 — 흡연·음주 (필수, 모델 입력)
흡연·음주 문항은 모델 학습 데이터(국민건강영양조사) 조사표 문구를 그대로 씀. **아래 문구·선택지를 바꾸지 말 것** (4주 재입력 때 기간 문구만 바뀜, §6.1).

**H1 흡연 (필수)**
```
현재 일반담배(궐련)를 피우십니까?
  ○ 매일 피움                       → SMOKING = "current"
  ○ 가끔 피움                       → SMOKING = "current"
  ○ 과거엔 피웠으나, 현재 피우지 않음   → SMOKING = "former"
  ○ 피운 적 없음                     → SMOKING = "never"
```
- 저장: `health_measurements.metric_code = SMOKING`, `value_code` = 위 값 (ERD v8 그대로). 모델 입력 `smoking`에 같은 값을 보냄
- 이 문항에 "전자담배 포함" 문구를 넣지 않음 (학습 데이터가 일반담배만 물음)

**H2 전자담배 (필수, 모델 입력 아님)**
```
현재 전자담배(궐련형 또는 액상형)를 사용하십니까?
  ○ 매일 사용   → ECIG = "daily"
  ○ 가끔 사용   → ECIG = "occasional"
  ○ 사용 안 함  → ECIG = "none"
```
- 저장: `health_measurements.metric_code = ECIG` (ERD v8에 신규 지표). 모델에는 보내지 않음
- 금연 칸 판정에는 쓰지 않음 (근거 연구가 일반담배 흡연자 대상, §2.2). 일반담배 흡연자가 전자담배도 쓰면 금연 미션 카드에 "전자담배도 함께 끊어요" 안내에만 사용

**H3 음주 빈도 (필수)** — 저장: `metric_code = ALCOHOL_FREQ`
```
최근 1년 동안 술을 얼마나 자주 마십니까?
  ○ 평생 술을 마셔 본 적 없음       → drink_freq = "never_lifetime"
  ○ 최근 1년간 전혀 마시지 않았다    → drink_freq = "none_past_year"
  ○ 한 달에 1번 미만               → drink_freq = "lt_monthly"
  ○ 한 달에 1번 정도               → drink_freq = "monthly"
  ○ 한 달에 2–4번                 → drink_freq = "2_4_per_month"
  ○ 일주일에 2–3번 정도            → drink_freq = "2_3_per_week"
  ○ 일주일에 4번 이상              → drink_freq = "4plus_per_week"
```

**H4 한 번 음주량** — 저장: `metric_code = ALCOHOL_AMOUNT` (H3가 `never_lifetime`·`none_past_year`가 아닐 때만 표시, 표시되면 필수)**
```
한 번에 술을 얼마나 마십니까?
  ○ 1–2잔  → drink_amount = "1_2"
  ○ 3–4잔  → drink_amount = "3_4"
  ○ 5–6잔  → drink_amount = "5_6"
  ○ 7–9잔  → drink_amount = "7_9"
  ○ 10잔 이상 → drink_amount = "10plus"
```
- H4를 표시하지 않으면 `drink_amount`는 보내지 않음 (`null`). 서버가 0으로 처리함

**잔 기준 안내 (H4 아래에 항상 표시, 매일 기록 §5의 절주 미션에도 같은 표 사용)**
| 술 | 1잔 | 병·캔으로 셀 때 |
|---|---|---|
| 소주 | 소주잔 1잔 | 1병(360ml) = 7잔 |
| 맥주 | 맥주잔 1잔 | 캔 355ml = 1.5잔 · 500ml(캔·병·생맥주 500cc) = 2잔 |
| 와인 | 와인잔 1잔 | 1병(750ml) = 5잔 |
| 막걸리 | 막걸리 사발 1잔 | 1병(750ml) = 3잔 |
| 양주 | 양주잔 1잔 | |
| 소맥 | 맥주잔 1잔 = 1잔 | |

화면 문구: "소주·양주 구분 없이 각각의 술잔으로 세어 주세요."

### 1.2 W04-2 생활습관 설문 (챌린지 판정 전용, 모델 입력 아님)
- 시드: 새 설문 버전 `survey_type = initial_lifestyle`, `version = v2` (4주 재설문은 `interim_lifestyle` `v2`, 문구는 §6.1). 기존 v1(BREAKFAST·EATOUT·AEROBIC)은 `active_to`를 닫음
- `survey_questions.required = false`, `survey_options.model_value_code = NULL`, 나트륨 지수 점수는 `survey_options.numeric_score`
- 문항 코드(`question_code`): N0–N10, P1, P2, E1, B1, BP_MEASURE_METHOD
- 모든 문항 선택지형(P2 걸음 수만 숫자). 건너뛰기 가능 (각 문항에 "건너뛰기" 버튼)
- **건너뛴 문항이 있어도 예측은 그대로 진행.** 그 문항이 필요한 카테고리만 추천에서 빼고 W09에 "설문을 마치면 추천돼요"로 표시 (§3.4)
- 설문 상단 안내 문구: "챌린지 추천에 쓰는 설문이에요. 위험도 계산에는 쓰지 않아요."
- 설문 단계: ① 짠맛·나트륨 → ② 신체 활동 → ③ 외식·배달 → ④ 아침 식사 → ⑤ 혈압 측정 → 완료

**① 짠맛·나트륨 — 나트륨 지수 11문항** (출처: 부록 B-1. 11문항 모두 답해야 지수 계산, 하나라도 건너뛰면 나트륨 카테고리 추천 제외)

N0 (짠맛 습관)
```
평소 음식을 어떻게 드시나요?
  ○ 싱겁게 10 · ○ 약간 싱겁게 20 · ○ 보통 30 · ○ 약간 짜게 40 · ○ 짜게 50
```

N1–N5 (식행동, 선택지 공통: 전혀 그렇지 않다 / 약간 그렇다 / 보통이다 / 많이 그렇다 / 매우 그렇다)

|---|---|---|
| N1 | 국수·라면의 국물을 다 마신다 | 2 · 4 · 6 · 8 · 10 |
| N2 | 음식에 소금이나 간장을 습관적으로 더 넣는다 | 2 · 4 · 6 · 8 · 10 |
| N3 | 회·전·튀김에 간장이나 고추장을 많이 찍어 먹는다 | 2 · 4 · 6 · 8 · 10 |
| N4 | 가공식품을 살 때 나트륨 함량을 확인한다 | **10 · 8 · 6 · 4 · 2** (역점수) |
| N5 | 외식할 때 싱겁게 해달라고 요청한다 | **10 · 8 · 6 · 4 · 2** (역점수) |

N6–N10 (빈도, 선택지 공통: 월 3회 이하 / 주 1–2회 / 주 3–6회 / 하루 1회 / 하루 2–3회)
| 문항 | 문구 | 점수 (월 3회 이하 → 하루 2–3회) |
|---|---|---|
| N6 | 국이나 찌개를 얼마나 자주 드시나요? | 2 · 4 · 6 · 8 · 10 |

## 2. 계산값 (서버, ① 직후 저장)

ERD `derived_feature_definitions`에 아래 `feature_code` 4개를 등록하고(`source_type = survey`), 계산 결과는 `user_classifications.classification_value`(JSON)에 함께 저장함. 분류는 건강정보 기반(`smoker`·`drinker`·`bp_160_100`·`overweight`)이면 `health_record_id`, 설문 기반이면 `survey_instance_id`로 저장 (ERD v8 `user_classifications`).

| `feature_code` | 값 | 계산 |
|---|---|---|
| `sodium_est_mg` | 숫자 (mg/일, 정수 반올림) | §2.1 |
| `sodium_index` | 숫자 (소수 첫째 자리) | §2.1 |
| `sodium_grade` | `careful_low` / `very_moderate` / `moderate` / `careful_high` / `severe` / `not_applicable` | §2.1 표, 적용 범위 밖이면 `not_applicable` |
| `steps_target` | 정수 | `baseline_steps` + 2,000 (P2 미응답이면 저장하지 않음) |

### 2.1 나트륨 지수
```
성별값    = 남 1, 여 2
연령대값  = 29세 이하 1 · 30–39세 2 · 40–49세 3 · 50–59세 4 · 60세 이상 5
BMI       = 몸무게(kg) ÷ 키(m)²   (W04 값)
짠맛점수  = N0 점수 (10–50)
식행동합  = N1~N10 점수 합 (20–100)

추정 나트륨(mg/일) sodium_est_mg = −191.9 − 705.2×성별값 + 189.6×연령대값 + 130.6×BMI + 24.2×짠맛점수 + 18.5×식행동합
나트륨 지수 sodium_index        = sodium_est_mg ÷ 20   (반올림 전 sodium_est_mg로 계산한 뒤 소수 첫째 자리 반올림)
```

| `sodium_index` | 추정 섭취량 | `sodium_grade` | 화면 표시 |
|---|---|---|---|
| 75 미만 | 1,500mg 미만 | `careful_low` | 주의 (약간 적음) |
| 75–100 | 1,500–2,000mg | `very_moderate` | 매우 적정 |
| 100 초과–150 | 2,000–3,000mg | `moderate` | 적정 |
| 150 초과–250 | 3,000–5,000mg | `careful_high` | 주의 (많음) |
| 250 초과 | 5,000mg 초과 | `severe` | 심각 |

- **원문 대조 (2026-10-08)**: 계수·코딩은 원문 Table 2, 판정 구간은 Table 7과 같음 ([원문](https://synapse.koreamed.org/articles/1162198))
  - Table 2: 상수 −191.9 · 성별 −705.2 (남 1, 여 2) · 연령대 189.6 (19–29세 1 ~ 60–69세 5) · BMI 130.6 · 짠맛 습관 24.2 (10–50) · 식행동 합 18.5 (20–100)
  - Table 7: 75–100 매우 적정 · 100 초과–150 적정 · 75 미만 또는 150 초과–250 주의 · 250 초과 심각 (초록의 "150–200"은 오기, 본문 Table 7 기준)
  - **대부분 `high_sodium`으로 나오는 것은 식의 특성임.** BMI 계수가 커서 40대 남성(BMI 22.9)은 가장 싱겁게 답해도 지수 약 163(주의)이 나옴. 원문에서도 성인 1,600명 중 주의 54.3% · 심각 24.3%
- **적용 범위**: 이 계산식은 고혈압·당뇨 진단이 없는 19–69세로 만든 식임. 아래 사용자는 지수를 계산하지 않고 `sodium_grade = not_applicable`로 저장, 추정 섭취량(mg)도 표시하지 않음
  - 나이 70세 이상, `htn_status` ≠ none, `diabetes` = true
  - 이 사용자는 `high_sodium`을 설문 응답과 무관하게 true로 둠 (소금 감량의 혈압 효과는 고혈압 환자·당뇨 환자에서도 확인됨, 부록 B-2·B-14). W09 나트륨 카드 문구: "혈압·혈당 관리를 위해 나트륨 줄이기를 권해요"
- 표시 위치: W09 나트륨 카테고리 카드, W11-2 비교 화면. 문구: "추정 나트륨 섭취량 약 ○,○○○mg/일 (설문 기반 추정치) · ○○(판정)". "측정"이라는 말을 쓰지 않음

### 2.2 사용자 분류 (`user_classifications.classification_code`)
| 코드 | 조건 |
|---|---|
| `smoker` | `SMOKING` = current (일반담배 현재 흡연. 전자담배만 쓰는 사람은 해당 안 됨) |
| `drinker` | `drink_freq` ∉ {never_lifetime, none_past_year} **그리고** `drink_amount` ∈ {3_4, 5_6, 7_9, 10plus} (한 번에 3잔 이상. 1–2잔만 마시는 사람은 해당 안 됨) |
| `high_sodium` | `sodium_grade` ∈ {careful_high, severe} **또는** `sodium_grade` = not_applicable (§2.1 적용 범위) |
| `low_activity` | `activity_code` ≠ 150plus |
| `has_baseline_steps` | `baseline_steps` ≠ null |
| `frequent_eatout` | `eatout_code` ∈ {5_6_week, 1_day, 2plus_day} **그리고** `high_sodium` (근거가 소금 감량 연구라 나트륨 조건을 함께 봄) |
| `breakfast_skip` | `breakfast_code` ∈ {3_4, 1_2, 0} (= 주 3일 이상 결식) |
| `bp_measurable` | 혈압 측정 ≠ difficult (4주 재입력 안내 문구 분기용, §5.3) |
| `bp_160_100` | W04 수축기 ≥ 160 **또는** 이완기 ≥ 100 |
| `overweight` | BMI ≥ 25 (BMI = W04 몸무게(kg) ÷ 키(m)², 서버 계산. 화면에 표시하지 않음) |

- 판정에 필요한 문항을 건너뛰었으면 그 분류는 만들지 않음 (예: P1 미응답 → `low_activity` 없음). 이 경우 그 카테고리는 §3.4의 "설문 미응답" 처리

## 3. 챌린지 추천·선택 (W09)

### 3.1 구성
- 미션 3개 = **고정 2개 + 선택 1개** (REQ-CHAL-003)
- 혈압 측정은 미션이 아님. 시작·4주 재입력 때만 입력 (§5.3). 3개 미션과 달성률에 넣지 않음
- **추천 판정은 §2.2 분류만 사용함.** 모델 출력의 `top_modifiable_factor`·`factors`와 ERD `factor_challenge_links`는 W06 결과 화면의 설명용이고 챌린지 추천에 쓰지 않음
- 카테고리 코드 (`challenge_categories`): `SMOKING` 금연 · `ALCOHOL` 절주 · `SODIUM` 나트륨 · `ACTIVITY` 신체 활동 · `EATOUT` 외식·배달 · `BREAKFAST` 아침 식사 · `WEIGHT` 체중 관리

### 3.2 고정 미션 2개
| 칸 | 조건 | 들어가는 미션 |
|---|---|---|
| 고정 1 (흡연 칸) | `smoker` | SMK-1 금연 |
| | `smoker` 아님 | 대체 순서(§3.3)의 첫 번째 미션 |
| 고정 2 (음주 칸) | `drinker` | ALC-1 절주 |
| | `drinker` 아님 | 대체 순서(§3.3)에서 고정 1과 **다른 카테고리**의 첫 번째 미션 |

### 3.3 대체 순서
위에서부터 조건이 맞는 첫 카테고리의 대표 미션을 넣음.

| 순서 | 카테고리 | 조건 | 대표 미션 |
|---|---|---|---|
| 1 | 나트륨 | `high_sodium` | NA-1 국물 남기기 |
| 2 | 신체 활동 | `low_activity` | `has_baseline_steps`면 ACT-1, 아니면 ACT-2 |
| 3 | 외식·배달 | `frequent_eatout` | OUT-1 |
| 4 | 아침 식사 | `breakfast_skip` | BRK-1 |
| 5 | (넣을 카테고리가 남아 있지 않음) | — | 그 칸은 비움. 화면: "지금 생활습관이 잘 유지되고 있어요" |

### 3.4 선택 미션 1개
- 후보 = 아래 카테고리별 조건을 만족하는 미션 중, 고정 미션과 **같은 미션이 아닌 것** 전부
- 사용자가 1개 선택. 선택하지 않으면 시작 버튼 비활성
- 후보가 0개면: 고정 미션으로 들어간 미션을 빼고 NA-1, NA-2, ACT-1(`has_baseline_steps`일 때), ACT-2, ACT-3(`bp_160_100`이 아닐 때), OUT-1, BRK-1 전체를 후보로 보여주고 상단에 "모든 생활습관이 잘 유지되고 있어요. 하고 싶은 미션을 하나 골라 보세요" 표시
- 설문 문항을 건너뛰어 분류가 없는 카테고리는 후보에서 빼고 "설문을 마치면 추천돼요" + 설문 바로가기 표시
- 완료한 미션도 다음 사이클 후보에 그대로 두고 "완료함" 표시와 함께 이어서 고를 수 있게 함. 카드에 "지난 4주 목표를 달성했어요! 습관이 자리 잡는 데는 보통 두 달 정도 걸려요. 이어서 해 볼까요?" 표시 (팀 결정 10/8. 사이클 28일 < 습관 형성 중앙값 66일, B-21. PRD REQ-CHAL-002 "완료한 챌린지는 후보에서 제외" 수정 필요)
- 미션 완료 기준: 사이클 종료 시 4주 달성률(§5.1) 80% 이상

| 카테고리 | 후보 조건 | 후보 미션 | 제외될 때 화면 문구 |
|---|---|---|---|
| 금연 | `smoker` | (고정 칸 전용, 선택 후보 아님) | — |
| 절주 | `drinker` | (고정 칸 전용, 선택 후보 아님) | — |
| 나트륨 | `high_sodium` | NA-1, NA-2 | 지수 150 이하: "추정 나트륨 섭취가 많지 않아요" |
| 신체 활동 | `low_activity` | ACT-1(`has_baseline_steps`일 때만), ACT-2, ACT-3(`bp_160_100`이면 제외) | 150plus: "운동 권장량(주 150분)을 이미 채우고 있어요" |
| 외식·배달 | `frequent_eatout` | OUT-1 | 외식 주 5회 미만: "외식·배달 횟수가 많지 않아요" / 나트륨 지수 150 이하: "추정 나트륨 섭취가 많지 않아요" |
| 아침 식사 | `breakfast_skip` | BRK-1 | "아침 식사를 잘 챙기고 있어요" |
| 체중 관리 | `overweight` | WT-1 | "지금 체중은 관리 미션 대상이 아니에요" |

- `bp_160_100` 사용자는 결과 화면에서 의료기관 상담 안내를 먼저 보여줌 (REQ-PRED-005와 같은 위치)

- **쓰지 않는 표현**: 나트륨·운동·외식·아침 미션에 "위험을 높인 요인"이라고 쓰지 않음 (모델 근거가 아님). "아침을 먹으면 혈압·체중이 내려가요"라고 쓰지 않음. "금연하면 혈압이 내려가요"라고 쓰지 않음. WT-1에 목표 체중 숫자, 감량 속도, "○kg 빼면 위험도가 ○% 내려가요"를 쓰지 않음 (모델로 목표를 정하지 않음)

## 5. 매일 기록 (W10)

### 5.1 공통 규칙
- 미션별 하루 1건. 같은 미션·같은 날짜 중복 저장은 409 (ERD `challenge_logs` unique)
- 수정은 당일만 가능, 지난 날짜 수정은 403 (REQ-CHAL-005)
- 저장 필드: `status` (`completed` / `failed` / `skipped`), `quantity`, `limit_exceeded`
- **주간 달성률 = 그 주 `completed` 건수 ÷ `weekly_target`** (100% 상한). `skipped`와 `failed`는 달성 수에 넣지 않음
- 주는 사이클 시작일부터 7일 단위 (1–4주, ERD `challenge_target_weeks`). 기록하지 않은 날은 저장하지 않음 (달성 수에 들어가지 않음)
- 알림은 하루 1회 이하 (REQ-CHAL-004)
- 실패를 질책하는 문구를 쓰지 않음 (REQ-CHAL-007)

### 5.2 미션별 기록 화면
| 코드 | 질문 | 선택지 → 저장값 |
|---|---|---|
| SMK-1 | 오늘 일반담배나 전자담배를 피우셨나요? | 아니오 → `completed` / 예 → `failed` + "몇 개비 피우셨나요?" 숫자 입력(선택) → `quantity` |
| ALC-1 (남) | 오늘 술을 드셨나요? | 안 마심 → `completed`, `quantity`=0 / 1잔 → `completed`, 1 / 2잔 → `completed`, 2 / **3잔 이상** → `failed`, 3, `limit_exceeded`=true |
| ALC-1 (여) | 오늘 술을 드셨나요? | 안 마심 → `completed`, 0 / 1잔 → `completed`, 1 / **2잔 이상** → `failed`, 2, `limit_exceeded`=true |
| NA-1 | 오늘 국·찌개·탕·라면의 국물을 남기셨나요? | 남겼어요 → `completed` / 국물 요리를 먹지 않았어요 → `completed` / 다 먹었어요 → `failed` |
| NA-2 | 오늘 음식에 소금이나 간장을 더 넣지 않으셨나요? | 넣지 않았어요 → `completed` / 넣었어요 → `failed` |
| ACT-1 | 오늘 걸음 수를 입력해 주세요 | 숫자 → `quantity`. `quantity` ≥ `steps_target` → `completed`, 미만 → `failed`. 캡처 첨부는 선택 (`challenge_proofs`) |
| ACT-2 | 오늘 숨이 조금 찰 정도로 빠르게 걸은 시간은? | 안 걸었어요 → `failed`, 0 / 30분 미만 → `failed`, 15 / 30분 이상 → `completed`, 30 |
| ACT-3 | 오늘 벽 스쿼트를 하셨나요? | 4번 모두 했어요 → `completed`, 4 / 일부만 했어요 → `failed` + 횟수(1–3) → `quantity` / 안 했어요 → `failed`, 0 |
| OUT-1 | 오늘 외식·배달 때 "싱겁게" 요청하셨나요? | 요청했어요 → `completed` / 외식·배달을 하지 않았어요 → `skipped` / 요청하지 않았어요 → `failed` |
| BRK-1 | 오늘 아침 식사를 하셨나요? | 했어요 → `completed` (사진 첨부 선택) / 안 했어요 → `failed` |
| WT-1 | 오늘 끼니마다 밥을 2/3공기 이하로 드셨나요? | 네 → `completed` / 아니요 → `failed` |

- ALC-1에서 `limit_exceeded`=true면 경고 문구 표시: "오늘은 권장량을 넘었어요. 건강을 위해서는 술을 마시지 않는 것이 가장 좋아요." 서비스 이용은 제한하지 않음 (REQ-CHAL-010)
- 잔 기준표(§1.1)를 ALC-1 기록 화면에 항상 표시

### 5.3 혈압 측정 (4주마다, 미션 아님)
- **언제**: 시작할 때(W04 최초 입력)와 4주 재입력 때(§6.1)만. 주간 혈압 기록은 없음 (`weekly_bp`는 쓰지 않음)
- **누가**: 모든 사용자. 혈압계가 없어도 약국·보건소에서 잰 값을 넣으면 됨
- **측정 안내 문구** (W04·4주 재입력의 혈압 칸 위에 그대로 표시, 근거 B-22)
  ```
  아침이나 저녁 중 편한 시간에 재 주세요. 다음에도 같은 시간대에 재야 비교할 수 있어요.
  · 아침에 잴 때: 일어난 지 1시간 안에, 화장실에 다녀온 뒤, 아침 식사나 약을 먹기 전에 재요
  · 저녁에 잴 때: 잠자리에 들기 전 1시간 안에 재요
  · 재기 30분 전부터는 커피, 운동, 흡연, 목욕, 음주를 피해 주세요
  · 의자에 앉아 1~2분 쉰 다음, 1~2분 간격으로 두 번 재요
  · 소매를 걷고 맨팔에 감는 게 좋아요 (얇은 옷이라면 옷 위에 감아도 괜찮아요)
  ```
  - `bp_measurable`이 아니면(어렵다) 위 문구 아래에 "집에 혈압계가 없으면 가까운 약국이나 보건소에서 재도 돼요" 추가
- **입력**: 첫 번째·두 번째 측정값(수축기·이완기) 4칸 → 평균(소수 첫째 자리 반올림)을 `SBP`·`DBP`로 저장. 두 번째 값을 비우면 첫 번째 값 저장
- **"다음에도 같은 시간대"는 서비스 규칙**임 (전후 비교를 위해). 지침은 진단에 1주 이상, 경과 확인에 5–7일 측정을 권하지만, 이 서비스는 진단이 아니라 변화 확인용이라 4주마다 1회로 정함
- 대시보드 혈압 추이: 시작·4주 재입력 값만 점으로 표시, 140/90 기준선 (REQ-DASH-010)

### 6.2 처리
1. §2 계산값 다시 생성 (나트륨 지수 등)
2. 모델 A·B 재예측: **최초 예측과 같은 `model_version`일 때만** 전·후 비교에 사용 (NFR-ARCH-004). 버전이 다르면 비교 화면에서 "모델 B 결과 변화" 항목을 표시하지 않음. 모델 B가 `skipped`면(4주 사이 고혈압 진단 등) 그 항목만 빼고 나머지는 표시
3. W11-2 비교 화면 표시 항목 (위에서부터)
   - 혈압 변화 (최초 → 4주). 아래에 "한 번 잰 값이라 차이가 작으면 측정 오차일 수 있어요" 표시
   - 미션별 달성률
   - 추정 나트륨 섭취량 변화 (mg/일)
   - 몸무게·허리둘레 변화 (WT-1 참여자, 정상 범위와 함께 표시, §6.3)
   - 습관 변화 (음주·흡연·운동·외식·아침 응답 비교)
   - 모델 A·B 결과 변화
4. 다음 사이클 추천은 4주 재입력 값으로 §2·§3을 다시 적용 (ACT-1 `steps_target`도 4주 P2 값으로 새로 계산)

### 6.3 체중·허리둘레 정상 범위 (WT-1)
- 모델을 쓰지 않음. 목표 체중 숫자·감량 속도를 정하지 않음 (2차 멘토링 10/7)
- 키 기준 정상 체중 = 18.5 × 키(m)² ~ 22.9 × 키(m)² kg (정수 반올림). BMI 값은 화면에 표시하지 않음
- 허리둘레 기준: 남 90cm 미만 · 여 85cm 미만 (대상 판정에는 쓰지 않음, 4주 결과 지표로만 표시)
- 표시 위치: W09 WT-1 카드, W11-2 비교 화면 (시작 값 → 4주 값)
- 다음 사이클 `overweight` 판정은 4주 재입력 몸무게로 다시 계산 (§6.2-4)
- 행동을 밥 양으로 정한 이유 (단순 환산, 실제 감량은 이보다 적음, B-19)

| 행동 (주 5일 × 4주) | 줄이는 열량 | 4주 체중 (상한) | 수축기 혈압 (B-15) |
|---|---|---|---|
| 끼니마다 밥 1/3공기 덜 먹기 | 밥 1공기 210g ≈ 290kcal (B-20) → 1/3 ≈ 100kcal × 3끼 = 300kcal/일 → 6,000kcal | 약 0.8kg | 약 −0.8mmHg |
| 빠르게 걷기 30분 (비교) | 4.3 MET (B-18), 70kg 기준 휴식 대비 약 115kcal/회 → 2,300kcal | 약 0.3kg | 약 −0.3mmHg |

  - 걷기는 체중으로는 효과가 작아 체중 미션 수단으로 쓰지 않음. 걷기의 혈압 효과(−4mmHg, B-5)는 체중과 별개라 ACT-2로 둠
  - 밥 양 0.8kg/4주는 대한비만학회 1차 목표(6개월 내 체중 5–10%, B-16)의 하한 속도(70kg 기준 4주 약 0.5kg)와 같은 수준

| 모델 B (현재 혈압 경계군) | 현재 흡연 오즈비 0.78, 과거 흡연 0.67 → **흡연하면 위험이 내려가는 것처럼 나옴** (반대 방향) | **요인 목록에 표시하지 않음** (`direction_matches_expectation = false`, `모델_연결_명세.md` §3) |

- 흡연은 혈압을 크게 올리기보다 **혈관 자체를 손상시켜** 심근경색·협심증 위험을 높임. 그래서 결과가 관상동맥질환인 모델 A에서는 잡히고, 결과가 "현재 혈압"인 모델 B에서는 잘 잡히지 않음
- 한 시점 조사에서 흡연자의 혈압이 비흡연자와 비슷하거나 더 낮게 나오는 것은 다른 나라 조사에서도 보고된 현상임. 영국 국가조사(3만 3천여 명)에서 흡연자의 수축기 혈압이 더 높았던 집단은 나이 많은 남성뿐이었고, 가볍게 피우는 여성은 오히려 낮았음 (부록 B-13)
- 과거 흡연이 더 낮게 나오는 이유는, 건강 문제를 알게 된 뒤 담배를 끊고 관리 중인 사람이 섞여 있기 때문으로 추정함
- 정리: **"흡연이 혈압에 좋다"는 뜻이 아님.** 금연 미션은 모델 A와 문헌(부록 B-7: 하루 1개비만 피워도 관상동맥질환 초과 위험이 하루 20개비의 남 46% · 여 31%)을 근거로 씀
