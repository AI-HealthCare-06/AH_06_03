체험 버전 안내 (이용약관 보충)

파이온은 생활습관 관리를 위한 위험 신호 안내 서비스입니다. 질병 진단을 돕는 서비스가 아닙니다.

파이온은 학생 팀이 만든 체험 버전입니다. 정식 서비스가 아니며, 예고 없이 내용이 바뀌거나 일시적으로 중단될 수 있습니다. 체험 기간은 [시작일]부터 [종료일]까지입니다.

이용자의 약속

  • 본인의 정보만 입력해 주세요. 다른 사람의 정보를 대신 입력하지 마세요.
  • 부담되시면 실제와 다른 값으로 입력하셔도 됩니다. 이 경우 결과는 참고가 되지 않습니다.
  • 서비스에 무리를 주는 행위(과도한 접속 등)는 하지 마세요.

서비스의 한계

  • 분석 결과와 챌린지 안내는 통계 모델에 기반한 참고 정보이며, 진단·치료·처방이 아닙니다.
  • 체험 버전의 분석 결과는 실제와 다를 수 있습니다.
  • 건강에 이상을 느끼거나 증상이 있으면 결과와 상관없이 의사와 상담해 주세요.

데이터와 삭제

  • 마이페이지에서 탈퇴하시면 입력하신 건강정보·설문·챌린지 기록·일기·사진이 바로 삭제되고, 이메일을 누구인지 알 수 없는 값으로 바꾼 계정 기록만 남습니다.
  • 탈퇴하지 않으신 분의 정보는 체험이 끝나는 [종료일]부터 일주일 안에 저희가 삭제합니다.
  • 서버 안전을 위한 백업 사본에는 최대 일주일 더 남아 있다가 지워집니다. 모든 곳에서 사라지는 시점은 탈퇴 또는 체험 종료 후 최대 2주입니다.
  • 마이페이지에서 내 데이터를 내려받을 수 있습니다.

처리 위탁과 국외 이전

서버는 Amazon Web Services(서울 리전)에서 운영합니다. 개인정보 처리를 맡기는 곳은 이곳뿐입니다. 검진 결과지 사진 자동 입력은 현재 제공하지 않습니다.

개인정보의 파기

회원 탈퇴를 요청하면 비밀번호로 다시 확인한 뒤, 이용자 번호가 연결된 건강정보·설문·분석·챌린지·캘린더 기록과 동의 기록, 로그인 세션을 데이터베이스에서 삭제합니다. 계정 행은 지우지 않고 이메일을 익명 값으로 바꾸고 비밀번호를 사용할 수 없는 값으로 교체해 로그인할 수 없게 합니다. 탈퇴 요청·처리 시각과 삭제 건수 요약은 기록으로 남습니다. 탈퇴한 뒤에도 같은 이메일로 다시 가입할 수 있습니다.

정보주체의 권리와 행사 방법

  • 열람: 마이페이지의 "내 데이터 내려받기"로 내 정보를 받을 수 있습니다.
  • 정정: 건강정보는 "건강정보 수정하기"에서 직접 고칠 수 있습니다. 생년월일·성별은 마이페이지의 "내 정보"에서 직접 고칠 수 있고, 이메일 정정은 아래 연락처로 요청해 주세요.
  • 삭제: 마이페이지의 "회원 탈퇴"로 삭제할 수 있습니다.
  • 처리정지: 마이페이지의 "건강정보 처리 동의 철회"로 건강정보 처리를 멈출 수 있습니다. 계정은 유지됩니다.
  • 화면에서 할 수 없는 요구는 문의 폼으로 보내 주세요. 문의에 적어 주신 정보는 답변이 끝나면 삭제합니다.

안전성 확보 조치

  • 비밀번호는 bcrypt로 해시해 저장하며 원문은 저장하지 않습니다.
  • 서비스에 접속하는 구간은 HTTPS로 암호화됩니다.
  • 이메일·생년월일·성별, 건강정보, 설문 답변, 챌린지 기록, 건강 할 일, 캘린더 일기와 사진은 서버 데이터베이스에 항목별 암호화 없이 저장됩니다.
  • 서버를 관리하거나 서비스를 올릴 수 있는 개발팀원 4명이 서비스 점검을 위해 저장된 값을 볼 수 있으며, 테스트 목적 외에는 사용하지 않습니다.
  • 로그인 토큰: 접근 토큰은 짧은 유효기간(현재 설정 30분)을 두고, 재발급용 토큰은 해시 값만 저장합니다.
  • 건강정보 동의를 철회하면 건강정보를 쓰는 기능(건강정보·설문·분석·챌린지)의 서버 요청이 막힙니다.
  • 데이터베이스는 서버 밖에서 직접 접속할 수 없도록 막아 두었고, 접속 정보와 비밀값은 저장소에 올리지 않고 서버 설정 파일에만 둡니다. 서버 상태와 백업은 자동으로 점검하고 이상이 있으면 알림을 받습니다.

로그인 정보 저장

로그인을 유지하기 위해 이 브라우저의 저장소(localStorage)에 로그인 토큰을 저장합니다. 로그아웃하거나 탈퇴하면 지워집니다.
